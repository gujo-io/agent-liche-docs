# 에이전트 연결

[안내서 처음으로](../README.md)

리체는 대화의 답을 직접 만들지 않아요. 여러분의 컴퓨터에 설치한 AI 에이전트가 답을 만들고, 리체는 그 대화를 보여 주며 표정과 몸짓으로 반응해요. 에이전트는 리체에 들어 있지 않으니 따로 설치해야 해요.

## 먼저 알아 둘 것

- **에이전트의 계정과 요금은 따로예요.** 에이전트를 쓰려면 그 에이전트의 계정, 구독이나 API 키가 따로 필요해요. 요금도 그 서비스에 따로 내요. 리체는 에이전트의 로그인 정보나 키를 받지도 저장하지도 않아요.
- **에이전트는 ACP로 연결해요.** 리체는 ACP(Agent Client Protocol)라는 공개 방식으로 에이전트와 이야기해요. Claude Code와 Codex는 ACP를 직접 말하지 않아서, 둘 사이를 이어 주는 ACP 어댑터를 따로 설치해야 해요.
- **대화 내용은 에이전트에게 가요.** 보낸 메시지는 연결한 에이전트 프로그램에 전달되고, 에이전트는 그 내용을 자기 AI 서비스로 보낼 수 있어요. 자세한 내용은 [개인정보와 데이터](privacy.md)에 있어요.
- **로그인을 먼저 끝내요.** 에이전트를 연결하기 전에 터미널에서 그 에이전트를 한 번 실행해 로그인과 모델 설정을 끝내 두세요. 로그인을 기다리는 에이전트는 리체에게 답하지 못해요.

## 연결할 수 있는 에이전트

| 에이전트 | 필요한 것 | macOS (예정) | Windows |
| --- | --- | --- | --- |
| OpenClaw | OpenClaw 설치 (`openclaw acp`) | 첫 실행 안내의 목록에서 고르기. 실제 대화를 확인했어요 | 명령으로 연결 (확인 중) |
| Hermes | Hermes 설치 (`hermes-acp`) | 첫 실행 안내의 목록에서 고르기 (확인 중) | 연결 설정 창의 Hermes 카드. 실제 대화를 확인했어요 |
| Claude Code | Claude Code와 ACP 어댑터 `claude-agent-acp` | 첫 실행 안내의 목록에서 고르기 (확인 중) | 명령으로 연결 (확인 중) |
| Codex | Codex와 ACP 어댑터 `codex-acp` | 첫 실행 안내의 목록에서 고르기 (확인 중) | 명령으로 연결 (확인 중) |
| 그 밖의 ACP 에이전트 | 그 에이전트를 ACP로 띄우는 명령 | **에이전트로 연결하기** 또는 명령으로 연결 (확인 중) | 명령으로 연결 (확인 중) |
| 리체 브릿지 (에이전트 리체) | 별도 프로그램 | 목록에 보이지만 지금 판매하는 패키지에는 들어 있지 않아요 (확인 중) | 연결 설정 창에 카드가 보이지만 지금 판매하는 패키지에는 들어 있지 않아요 (확인 중) |

"(확인 중)"은 처음부터 끝까지 실제로 대화해 보는 확인을 아직 마치지 않았다는 뜻이에요. 연결 방법은 같지만, 에이전트의 버전에 따라 동작이 다를 수 있어요.

## 에이전트 설치하기

아래에 각 에이전트의 공식 안내 주소를 적었어요. 설치 방법은 각 프로젝트가 정하므로 그쪽 안내를 따라요.

### OpenClaw

- 홈페이지: https://openclaw.ai
- 설치한 뒤 터미널에서 `openclaw acp`가 실행되는지 확인해요.

### Hermes

- 홈페이지: https://hermes-agent.nousresearch.com
- 설치 프로그램이 `hermes-acp` 명령을 만들어요. macOS에서는 보통 `~/.local/bin/hermes-acp`, Windows에서는 `%LOCALAPPDATA%\hermes\bin\hermes-acp.exe`에 있어요.
- Hermes가 "모델을 정해 달라"고 하면 터미널에서 `hermes model`을 실행해 모델을 정한 뒤 다시 골라요.

### Claude Code

1. Claude Code를 설치하고 터미널에서 `claude`를 한 번 실행해 로그인해요. Claude 구독이나 Anthropic API 키가 필요해요.
2. Node.js를 설치해요.
3. ACP 어댑터를 설치해요.

```bash
npm install -g @agentclientprotocol/claude-agent-acp
```

설치하면 `claude-agent-acp` 명령이 생겨요. 어댑터 안내: https://github.com/agentclientprotocol/claude-agent-acp

예전 이름인 `claude-code-acp`가 설치돼 있어도 리체가 찾아요.

### Codex

1. Node.js를 설치해요.
2. ACP 어댑터를 설치해요. 어댑터에 Codex가 함께 들어 있어요.

```bash
npm install -g @agentclientprotocol/codex-acp
codex-acp --version
```

3. ChatGPT 계정이나 OpenAI API 키로 로그인해요. 어댑터 안내: https://github.com/agentclientprotocol/codex-acp

## macOS에서 연결하기 (예정)

macOS 판에서는 첫 실행 안내의 **"리체를 연결해주세요"** 단계에서 연결해요. 안내를 이미 닫았다면 대화창의 **리체 연결하기**를 누르거나 **리체 설정 › 연결 › 연결 설정 열기**를 눌러요.

- **이 컴퓨터에서 찾은 연결:** 리체는 OpenClaw, Hermes, Claude Code, Codex를 PATH와 `/opt/homebrew/bin`, `/usr/local/bin`, `~/.local/bin`에서 찾아요. 찾은 줄을 고르고 **연결하기**를 눌러요.
- **에이전트로 연결하기:** 에이전트가 목록에 없거나 다른 곳에 설치돼 있으면 이 줄의 **복사**를 눌러요. 복사한 글을 쓰고 있는 에이전트에게 붙여 넣으면, 에이전트가 리체의 MCP 서버를 등록하고 스스로를 리체의 대화 상대로 연결해요. 에이전트가 "Connected"로 시작하는 답을 받으면 끝이에요.

## Windows에서 연결하기

### Hermes

1. Hermes를 설치해요.
2. 대화창의 **연결 설정**을 누르거나 **리체 설정 › 연결 › 연결 설정 열기**를 눌러요.
3. **Hermes** 카드가 **설치 안 됨**이면 **다시 확인**을 눌러요.
4. **설치됨**이 된 Hermes 카드를 눌러요. **연결됨**이 보이면 끝이에요.

### Windows에서 다른 에이전트 연결하기

연결 설정 창에 없는 에이전트(Claude Code, Codex, OpenClaw 등)는 명령 프롬프트나 PowerShell에서 리체의 대화창 프로그램 `LicheInput.exe`에 `--connect`를 주어 연결해요. (확인 중)

1. 리체를 켜 둬요.
2. 리체 폴더 안의 `a001_Cartoon\Binaries\Win64` 폴더에서 `LicheInput.exe`의 전체 경로를 확인해요. (확인 중: 판매 패키지의 폴더 구조)
3. PowerShell에서 아래처럼 실행해요. `--` 뒤에는 그 에이전트를 ACP로 띄우는 명령을 써요.

```powershell
& "<리체 폴더>\a001_Cartoon\Binaries\Win64\LicheInput.exe" --connect -- claude-agent-acp
```

| 에이전트 | `--` 뒤에 쓸 명령 |
| --- | --- |
| Claude Code | `claude-agent-acp` |
| Codex | `codex-acp` |
| OpenClaw | `openclaw acp` |

4. "Connected"로 시작하는 줄이 나오면 연결된 거예요. 다른 글이 나오면 그 내용을 그대로 고객지원에 보내 주세요.

`--connect`로 연결하면 지금 연결된 상대가 바로 바뀌어요. 답을 기다리는 중이거나 승인 요청이 남아 있으면 바뀌지 않아요.

## 에이전트가 할 수 있는 일

- **대화:** 두 모드(일상, 업무)마다 따로 대화를 이어 가요. 에이전트는 모드마다 자기 작업 폴더(macOS `~/Liche/<모드>`, Windows `문서\Liche\<모드>`)에서 일해요.
- **승인 요청:** 에이전트가 도구를 쓰려고 하면 대화창에 **승인**과 **거절**이 나와요. 리체는 스스로 승인하지 않아요. **■ 중지**를 누르거나 연결이 끊기면 남은 승인 요청은 모두 취소돼요.
- **리체의 MCP 서버:** 에이전트가 리체의 MCP 서버(`LicheInput --mcp`)를 등록하면 리체의 표정과 동작을 바꾸거나 리체의 말풍선으로 짧은 말(500자까지)을 할 수 있어요. 이 서버로는 대화 기록, 설정, 키를 읽을 수 없어요.
- **모델과 생각 깊이:** 에이전트가 고를 수 있는 모델을 알려 주면 **리체 설정 › 모드 › 일상(또는 업무) › 모델과 생각 깊이**에서 모드마다 고를 수 있어요. 에이전트가 알려 주지 않으면 이 항목은 쉬어요.
- **첨부:** 연결이 첨부를 지원할 때만 입력칸에 첨부 단추가 보여요.

## "응답하지 않아요"가 뜰 때

리체가 에이전트를 띄운 뒤 45초 안에 답을 받지 못하면 대화창에 이런 줄이 한 번 떠요.

> (에이전트 이름)가 응답하지 않아요. 에이전트가 켜져 있는지 확인해 주세요. 리체가 잠시 뒤 다시 연결해 볼게요.

macOS에서는 "macOS 권한 확인 창이 떠 있으면 먼저 답해 주세요."라는 문장이 함께 나와요. 이때 리체 설정의 연결 카드는 **확인 필요**와 같은 이유를 보여 줘요.

아래 순서로 확인해요.

1. **권한 창 확인:** 화면 어딘가에 macOS나 Windows의 권한 확인 창이 떠 있으면 먼저 답해요. 에이전트가 그 답을 기다리느라 멈춰 있을 수 있어요.
2. **에이전트 직접 실행:** 터미널에서 그 에이전트를 직접 실행해 로그인이나 첫 설정을 묻지 않는지 확인해요. 묻는다면 끝내 두세요.
3. **설치 위치 확인:** 터미널에서 `openclaw acp`, `hermes-acp`, `claude-agent-acp`, `codex-acp` 같은 명령이 실행되는지 확인해요. 명령을 찾지 못하면 리체도 찾지 못해요.
4. **잠시 기다리기:** 리체는 15초 뒤에 에이전트를 새로 띄워 다시 연결해 봐요. 다시 실패하면 기다리는 시간을 두 배씩 늘려 최대 5분까지 기다리며 계속 시도해요. 늦게라도 에이전트가 답하면 그대로 이어져요.
5. **다시 고르기:** 그래도 안 되면 연결을 다시 골라요. macOS는 **리체 연결하기**나 **연결 설정 열기**, Windows는 **연결 설정** 창에서 다시 골라요.

에이전트가 실행되지 않거나 연결이 끊기면 "…를 실행하지 못했어", "… 연결이 끊겼어"처럼 무엇을 확인할지 알려 주는 안내가 나와요. 안내대로 고친 뒤 다시 골라요.

## 연결을 바꾸거나 끊기

- 다른 에이전트로 바꾸려면 위의 연결 방법으로 새 에이전트를 고르면 돼요. 저장한 순간 새 연결로 바뀌어요.
- 어느 모드든 답을 기다리는 중이거나 승인 요청이 남아 있으면 연결을 바꿀 수 없어요. **■ 중지**를 누르거나 답이 끝나기를 기다린 뒤 바꿔요.
