# 처음 실행

[안내서 처음으로](../README.md) · [English](../en/docs/first-run.md)

리체를 처음 켜면 에이전트를 연결하는 안내가 나와요. macOS와 Windows는 안내의 모습이 달라요.

## 에이전트가 연결되기 전의 리체

리체의 답은 연결한 에이전트가 만들기 때문에, 에이전트가 없으면 리체는 대답하지 못해요. 그동안 리체는 카드 안에서 꾸벅꾸벅 졸고, 머리 위에 Zz가 떠요. 에이전트가 연결되면 리체가 잠에서 깨어나 원래 모습으로 돌아와요.

- 리체는 시간이 지났다고 졸지 않아요. 연결이 없거나 끊겼을 때만 졸아요.
- 졸고 있을 때 리체를 누르면 잠깐 깼다가 다시 졸아요.
- 연결해 둔 에이전트가 응답하지 않으면 카드 아래쪽에 회색 **연결 안 됨**이 보여요.

## macOS: 화면 전체를 쓰는 첫 실행 안내

macOS 판은 처음 실행할 때 화면 전체를 쓰는 짧은 이야기로 시작해요. 창 위쪽의 **이전**과 **다음 단계** 화살표로 단계 사이를 오갈 수 있어요.

1. **"어디선가 새근새근 숨소리가 들려요"**: **살짝 깨워 볼까?**를 눌러요. 아래 **사용권 계약 (EULA) 보기**에서 [사용권 계약](../legal/eula.md)을 읽을 수 있어요.
2. **"으음... 여기서 나가고 싶어요..."**: 리체가 나타나 처음으로 말해요. **내가 꺼내 줄게**를 눌러요.
3. **"리체를 연결해주세요"**: 에이전트를 고르는 단계예요. **리체의 대답은 연결한 AI 에이전트가 만들어요.** 방법은 두 가지예요.
   - **에이전트로 연결하기:** 이미 쓰고 있는 에이전트에게 연결을 맡기는 방법이에요. **복사**를 누르면 연결 방법이 적힌 글이 클립보드에 들어가요. 그 글을 에이전트(예: 터미널의 Claude Code나 Codex)에게 붙여 넣으면 에이전트가 스스로 리체에 연결해요. 연결되면 이 줄에 **연결됨**이 보여요.
   - **이 컴퓨터에서 찾은 연결:** 리체가 이 Mac에서 찾은 에이전트 목록이에요. OpenClaw, Hermes, Claude Code, Codex가 나오고, 각 줄 오른쪽에 **설치 안 됨**, **찾는 중**, **연결 중**, **연결됨**, **확인 필요** 같은 상태가 보여요. 설치된 줄을 고른 뒤 **연결하기**를 눌러요.
   - 설치된 것이 목록 위쪽에 먼저 나와요. 별도 프로그램인 **리체 브릿지**는 판매 패키지에 들어 있지 않아서, 이 Mac에 리체 브릿지를 따로 설치했을 때만 목록에 보여요.
   - **설치 안 됨**인 줄을 누르면 설치 순서와 복사할 명령을 보여 줘요. 리체가 대신 설치하지는 않아요. 설치하면 몇 초 간격으로 다시 찾아요. [설치 도우미 안내](agents.md#리체-안의-설치-도우미)를 확인해요.
   - 연결되면 단추가 **다음**으로 바뀌어요.
4. **"감정 판단 (JEV) · 선택"**: 감정 판단을 켜는 선택 단계예요. 키가 있으면 **키 입력**을 눌러 넣고, 없으면 **건너뛰기**를 눌러요. 건너뛰어도 리체는 정해진 규칙대로 반응해요. 자세한 내용은 [감정 판단 (JEV)](jev.md)에 있어요. 감정 판단 프로그램이 없는 설치에서는 이 단계가 나오지 않아요.
5. **"세부 설정을 확인해주세요"**: 연결된 에이전트와 위젯의 상태를 보여 줘요. **리체 내보내기**를 누르면 안내가 닫히고, 리체가 바탕 화면의 카드로 나와요.

안내 도중에 `Esc`를 누르거나 창을 닫으면 연결하지 않고 끝나요. 나중에 대화창의 **리체 연결하기**를 누르거나 **리체 설정 › 연결 › 연결 설정 열기**를 누르면 연결 단계부터 다시 열려요.

연결을 저장하고 30초가 지나도 연결되지 않으면 "연결을 저장한 지 30초가 지났어요. 그쪽 프로그램의 로그인 같은 자체 설정을 먼저 끝내 주세요."라는 안내가 나와요. 터미널에서 그 에이전트를 한 번 실행해 로그인을 끝낸 뒤 다시 골라요.

## Windows: 대화창 안내와 연결 설정 창

Windows 판은 화면 전체를 쓰는 안내 없이 바로 카드로 시작해요.

1. 대화창에 **"리체가 아직 바깥과 연결되지 않았어요"**와 **"리체의 대답은 연결한 AI 에이전트가 만들어요."**가 보여요. **연결 설정**을 눌러요. 옆 **사용권 계약 (EULA)**에서 [사용권 계약](../legal/eula.md)을 읽을 수 있어요.
2. **연결 설정** 창이 열리고 "리체랑 이야기할 길을 골라 줘."라는 안내와 함께 연결 카드가 보여요.
   - **Hermes:** Hermes 에이전트를 거쳐서 대화해요.
   - **리체 브릿지:** 리체의 기억과 성격을 담은 별도 프로그램이에요. 판매 패키지에 들어 있지 않아서, 이 PC에 리체 브릿지를 따로 설치했을 때만 카드가 보여요.
3. 각 카드에는 **설치됨**, **설치 안 됨**, **연결 중**, **연결됨**, **확인 필요** 중 하나가 보여요. **설치됨**인 카드를 한 번 누르면 저장하고 바로 연결해요.
4. 에이전트를 방금 설치했다면 **다시 확인**을 눌러 다시 찾게 해요.
5. 연결되면 카드에 **연결됨**이 보여요. **닫기**를 눌러 창을 닫아요.

연결 설정 창 아래쪽의 **감정 판단 켜기 (선택)**을 누르면 JEV 키를 넣는 창이 열려요. 켜면 대화의 일부를 미국의 TypeSafe AI로 보내요. 직접 받은 JEV 키와 별도 크레딧이 필요하며 입력 토큰에만 요금이 붙어요. 키가 없으면 그냥 두어도 돼요.

Claude Code, Codex, OpenClaw는 창 아래쪽 **다른 에이전트**에 있어요. **연결하기**로 연결하고, 설치하지 않았다면 **설치 방법 보기**를 눌러요. [에이전트 연결](agents.md)에서 공식 설치 안내를 확인해요.

연결 설정 창은 나중에 **리체 설정 › 연결 › 연결 설정 열기**로 다시 열 수 있어요.

## 첫 대화

대화 기록이 하나도 없으면 리체가 먼저 말을 걸어요. 대화창 아래 입력칸에 글을 쓰고 `Enter`를 누르면 보내져요.

- `Shift+Enter`: 줄 바꾸기
- 답을 기다리는 동안에는 같은 모드에서 새 메시지를 보낼 수 없어요. 쓰던 글은 입력칸에 그대로 남아요.
- **■ 중지**: 지금 답을 만드는 일을 멈춰요.
- 에이전트가 파일을 고치거나 명령을 실행하려고 하면 **확인이 필요해요**와 함께 **승인**, **거절** 단추가 나와요. 리체는 스스로 승인하지 않아요.
- 답을 기다리는 시간은 아래 [답을 기다리는 시간](#답을-기다리는-시간)에 정리했어요.

### 답을 기다리는 시간

| 상황 | 리체가 기다리는 시간 | 대화창에 보이는 것 |
| --- | --- | --- |
| 에이전트가 생각하거나 글을 쓰는 중 | 마지막 소식에서 **2분(120초)** | 2분 동안 아무 소식이 없으면 "응답이 없어요"를 남기고 기다리기를 멈춰요 |
| 에이전트가 도구를 쓰는 중(파일 읽기·고치기, 명령 실행, 승인 대기 등) | **2분 제한이 없어요.** 아무 소식 없이 **30분**이 지날 때만 멈춰요 | "작업 중이에요 · 3분 12초"처럼 보낸 뒤 지난 시간이 보여요. 30분 동안 아무 소식이 없으면 "작업이 30분 넘게 아무 소식이 없어서 기다리기를 멈췄어요"가 보여요 |

- 도구가 진행 상황을 보낼 때마다 30분은 처음부터 다시 세요. 오래 걸리는 빌드나 테스트도 소식이 이어지면 기다려요.
- 도구 시간 제한은 ACP 에이전트(Claude Code, Codex, OpenClaw, Hermes 등)에 적용돼요. 리체 브릿지 연결은 2분 규칙만 써요.
- 30분이 맞지 않으면 환경 변수 `LICHE_INPUT_TOOL_TIMEOUT_MINUTES`로 2분부터 1440분(24시간)까지 분 단위로 바꿀 수 있어요. 리체는 시작할 때 이 값을 한 번 읽어요.
  - Windows: **설정 › 시스템 › 정보 › 고급 시스템 설정 › 환경 변수**의 사용자 변수에 이름 `LICHE_INPUT_TOOL_TIMEOUT_MINUTES`, 값 `60`처럼 넣고 리체를 다시 켜요.
  - macOS: 터미널에서 `launchctl setenv LICHE_INPUT_TOOL_TIMEOUT_MINUTES 60`을 실행하고 리체를 다시 켜요. Mac을 다시 시작하면 이 값은 지워져요.
- 언제든 **■ 중지**로 기다리기를 멈출 수 있어요.

## 기본 조작

| 하고 싶은 일 | 방법 |
| --- | --- |
| 아이콘 열기 | 카드 오른쪽 위의 **⋯** 위에 포인터를 잠깐 올려요. 아래로 아이콘이 펼쳐져요 |
| 리체를 다른 창 위에 고정하기 | 펼친 아이콘 중 **고정핀**을 눌러요. 다시 누르면 풀려요 |
| 카드 옮기기 | **위치이동** 아이콘을 누른 채 끌어요. `⌥`(macOS)나 `Alt`(Windows)를 누른 채 카드에서 리체가 보이는 곳 아무 데나 끌어도 옮겨져요 |
| 카드 크기 바꾸기 | 유리 카드의 둥근 모서리 안쪽을 눌러 끌어요. 60%부터 160%까지 바뀌고, 끄는 동안 오른쪽 클릭하면 취소돼요. 놓은 뒤 잠깐 보이는 **100%로**를 누르면 원래 크기로 돌아와요 |
| 대화창 떼기와 붙이기 | 대화창 머리글의 붙이기·떼기 단추를 누르거나 **리체 설정 › 창 › 대화창 배치**에서 골라요. 같은 곳에서 **대화창 스타일**(Floating 또는 테두리가 있는 클래식 창)도 바꿔요 |
| 설정 열기 | 펼친 아이콘 중 **설정**(톱니바퀴)을 눌러 **리체 설정** 창을 열어요. 대화창 머리글의 톱니바퀴는 보고 있는 모드의 모델·생각 깊이 설정으로 바로 가요 |
| 일상과 업무 모드 바꾸기 | 대화창 위쪽의 말풍선 아이콘(일상)과 `</>` 아이콘(업무)을 눌러요 |
| 카드를 잃어버렸을 때 | **리체 설정 › 창 › 카드를 화면 가운데로**의 **옮기기**를 눌러요 ([문제 해결](troubleshooting.md) 참고) |

### 일상 모드와 업무 모드

리체에게는 대화가 두 개 있어요.

- **일상:** 잡담하는 대화예요. 리체는 기본으로 잠옷을 입고 안경을 쓰지 않아요.
- **업무:** 일을 맡기는 대화예요. 리체는 기본으로 메이드복을 입고 안경을 써요. 에이전트가 일하는 동안 노트북을 두드려요.

두 대화는 기록, 연결, 기다리는 답, 승인 요청이 모두 따로예요. 모드를 바꿔도 다른 모드의 일은 멈추지 않아요. 보고 있지 않은 모드에 새 답장이나 승인 요청이 오면 그 모드 아이콘에 주황색 점이 생기고 알림이 와요. 모드마다 입을 옷과 안경은 [리체 설정](settings.md)에서 바꿀 수 있어요.
