# 개인정보와 데이터

[안내서 처음으로](../README.md) · [English](../en/docs/privacy.md)

이 페이지는 리체가 컴퓨터에 무엇을 남기고, 어떤 때 바깥에 연결하는지 설명해요. Gujo 계정과 스토어의 개인정보 처리는 [Gujo 개인정보 처리방침](https://account.gujo.io/ko/privacy)을 따라요.

## 한눈에 보기

- 대화 기록과 설정은 여러분의 컴퓨터에 저장해요. 판매자의 서버에 올리지 않아요.
- 리체는 사용 통계 수집(텔레메트리)이나 오류 보고서 자동 전송을 하지 않아요.
- 판매용 리체는 외부 연결을 받는 포트를 열지 않아요. 에이전트와의 연결도 같은 컴퓨터의 프로그램 사이에서 이뤄져요.
- 리체의 대답은 연결한 AI 에이전트가 만들어요. 에이전트는 답을 만들려고 자기 AI 서비스로 대화를 보낼 수 있어요.
- JEV는 선택 기능이에요. 여러분이 켜고 키를 넣었을 때만 미국의 TypeSafe AI로 판단에 필요한 정보를 보내요.
- 새 버전 알림은 Gujo 스토어가 상품마다 만드는 작은 파일을 확인해요. 이때 스토어가 IP 주소를 알 수 있고, 원하지 않으면 끌 수 있어요.

## AI 안내

**리체의 대답은 연결한 AI 에이전트가 만들어요.** 리체 앱은 답을 직접 만들지 않고, 여러분이 고른 에이전트(Claude Code, Codex, OpenClaw, Hermes 등)가 만든 답을 보여 주며 표정으로 반응해요. AI가 만든 답은 틀릴 수 있어요. 중요한 내용과 에이전트가 실행하려는 작업은 직접 확인해 주세요. 리체는 같은 안내를 첫 실행의 연결 단계와 **리체 설정 › 리체 정보**에 보여 줘요.

## 컴퓨터에 남는 것

| 정보 | 저장하는 내용 |
| --- | --- |
| 대화 기록 | 일상·업무 대화 기록과 첨부 파일의 앱 전용 복사본 |
| 설정과 카드 위치 | 화면, 알림, 성능, 모드별 옷차림과 모델·생각 깊이, 위치·크기·고정핀 상태 |
| 연결 설정 | 에이전트 프로그램의 경로와 실행 인자. 에이전트의 로그인 정보나 API 키는 리체가 저장하지 않아요 |
| 지침 파일 | 리체의 성격과 말투 등을 정하는 지침. 처음에는 기본 지침이 들어 있고 여러분이 고칠 수 있어요. 에이전트가 읽어요 |
| JEV 키 | macOS 로그인 키체인 또는 Windows 사용자 계정으로 암호화한 파일 |
| 진단 기록과 오류 보고서 | 연결 상태, 오류 등 문제를 찾는 데 필요한 로컬 기록 |
| 새 버전 확인 기록 | 마지막으로 확인한 때와 그때 받은 버전 정보(`update-check.json`) |

정확한 위치와 지우는 방법은 [Windows 제거하기](install-windows.md#6-제거하기), [macOS 제거하기](install-mac.md#7-제거하기)에 있어요. **리체 설정 › 일반 › 기록 폴더 › 폴더 열기**로 데이터 폴더를 열 수도 있어요.

## 바깥에 연결하는 경우

리체 자신이 네트워크로 보내는 것은 아래 표가 전부예요. 캐릭터를 그리는 프로그램은 네트워크에 연결하지 않아요.

| 누가 | 어디로 | 언제 | 무엇을 보내나요 | 끄는 방법 |
| --- | --- | --- | --- | --- |
| 대화창 프로그램의 새 버전 확인 | `https://app.gujo.io/products/287/latest.json` (Gujo 스토어가 상품의 공개 파일로 만드는 버전 안내 파일) | 스스로는 하루에 한 번까지(시작하고 30초 뒤부터), 그리고 **리체 정보**를 열 때 10분에 한 번까지 | 파일을 달라는 요청뿐이에요. 주소에 덧붙이는 값(쿼리), 브라우저 정보(User-Agent), 쿠키, 계정, 기기 정보를 보내지 않아요. HTTPS로만 연결하고 다른 주소로 넘겨주는 응답은 따라가지 않아요. 연결하는 동안 스토어가 IP 주소를 알 수 있어요 | **리체 설정 › 리체 정보 › 새 버전 알림** 끄기 |
| 감정 판단 프로그램 `liche-judge` (선택) | `https://api.typesafe.ai/v1/systemone` (TypeSafe AI, 미국) | JEV를 켜고 직접 받은 키를 저장했을 때만. 키를 저장할 때 확인용 한 번, 판단하는 대화 한 번마다 두 번 | 그 대화의 내 메시지, 리체의 답과 말풍선, 바로 앞 대화 최대 다섯 번, 리체의 성격 설명과 기분, 그리고 요청에 붙는 키 | **리체 설정 › 연결 › 감정 판단 (JEV) · 선택** 끄기, 또는 키 없음 |
| 대화창 프로그램의 예전 파일 분류 창 | 여러분이 환경 변수에 적은 서버의 `/v1/systemone` | 환경 변수에 서버 주소와 키를 둘 다 적고 예전 독립 창에 파일을 놓았을 때만. 기본 서버는 없어요 | 놓은 파일의 이름과 세계관 이름 | 환경 변수를 설정하지 않으면 동작하지 않아요(기본값) |
| 기본 브라우저나 메일 앱 | 안내서, 사용권 계약, 제3자 고지, 고객지원, 스토어 페이지, 대화 안의 링크 | 여러분이 링크를 눌렀을 때만 | 브라우저가 페이지를 열 때 보내는 일반적인 정보 | 누르지 않으면 열지 않아요 |

새 버전 확인은 받은 내용대로 파일을 내려받거나 설치하지 않아요. 64 KiB까지만 읽고, 받은 파일 안의 링크도 스토어(`app.gujo.io`, `asset.gujo.io`)와 안내서(`github.com`)의 `https` 주소만 써요. 예전 파일 분류 창은 키와 요청 내용을 `curl`의 표준 입력으로 넘겨서, 다른 프로그램이 명령줄에서 키를 볼 수 없어요.

### 여러분이 연결한 에이전트

Claude Code, Codex, OpenClaw, Hermes 등은 **여러분의 컴퓨터에서 여러분이 설치하고 실행하는 별도 프로그램**이에요. 리체는 표준 입출력으로 메시지, 첨부, 승인에 대한 답을 전달해요. 에이전트는 답을 만들려고 자기 AI 서비스로 내용을 보낼 수 있어요. 에이전트를 설치하거나 `npx`로 실행하면 해당 프로그램을 내려받는 연결도 생길 수 있어요. 이런 연결은 리체가 아니라 그 프로그램의 것이고, 그 프로그램과 서비스의 약관·정책이 적용돼요.

별도로 연결한 `brain` CLI나 리체 브릿지도 같은 원칙을 따라요. 리체를 지워도 에이전트와 그 기록은 남아요.

리체의 MCP 연결은 네트워크 서버가 아니라 로컬 표준 입출력을 써요. 에이전트는 이를 통해 표정과 동작을 바꾸거나 짧은 말(최대 500자)을 보여 줄 수 있지만, 대화 기록·설정·키를 읽을 수는 없어요.

### 연결하지 않는 것

- 캐릭터를 그리는 리체 프로그램은 어떤 네트워크 연결도 하지 않아요. 사용 통계 수집, 원격 추적, 외부 연결을 받는 기능은 판매용 패키지에서 빼고 배포해요.
- 오류가 나면 컴퓨터에 오류 보고서가 남을 수 있지만, 오류 보고서를 보내는 프로그램은 패키지에 들어 있지 않아요.
- 판매용 패키지의 어느 프로그램도 연결을 받는 포트를 열지 않아서 방화벽 허용 창이 뜨지 않아요.

## 진단 파일 만들기

**리체 설정 › 리체 정보 › 진단 파일 만들기**를 누르면 바탕 화면에 고객지원용 zip 파일(`Liche-diagnostics-날짜-시각.zip`)이 생겨요. 파일을 만들기만 하며, 자동으로 전송하지 않아요.

- **들어 있는 것:** 대화창과 캐릭터 프로그램의 진단 기록, 최근 30일의 오류 보고서(메모리 덤프 제외), 설정 파일, 앱 버전·운영체제·화면 정보, 수집에서 빠진 파일 목록.
- **넣지 않는 것:** 대화 기록 파일, 첨부 파일, JEV 키 파일, 메모리 덤프, 저장한 연결의 실행 인자.
- **가리는 것:** 기록에 남은 대화 글, 키와 토큰, 계정·컴퓨터 이름과 이메일 주소, 경로에 들어 있는 사용자 이름. 대화 글은 글자 수만 남겨요.

가림 처리는 알려진 형식을 찾아 가리는 방식이라 모든 민감한 내용을 지운다고 보장하지는 않아요. 보내기 전에 zip 파일을 열어 내용을 확인해 주세요. 보내고 싶지 않은 파일은 빼도 돼요. 자세한 문의 방법은 [문제 해결](troubleshooting.md#문의할-때-알려-주시면-좋은-것)에 있어요.

## 알림과 승인 요청

**내용 미리보기**가 켜져 있으면 운영체제 알림에 답장의 앞부분(최대 100자)이 보여요. 다른 사람이 화면을 볼 수 있다면 **리체 설정 › 알림 › 내용 미리보기**를 꺼 두세요.

에이전트가 도구 사용 승인을 요청하면 리체는 **승인**이나 **거절**을 기다려요. 스스로 승인하지 않고 다른 창의 포커스를 빼앗지 않아요. 요청 내용을 확인한 뒤 답해요.
