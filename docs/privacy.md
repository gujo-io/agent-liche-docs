# 개인정보와 데이터

[안내서 처음으로](../README.md)

이 페이지는 리체 앱이 여러분의 컴퓨터에서 무엇을 저장하고 무엇을 바깥으로 보내는지 설명해요. Gujo 계정과 스토어에서 처리하는 개인정보는 [Gujo 개인정보 처리방침](https://account.gujo.io/ko/privacy)을 따라요.

## 한눈에 보기

| 정보 | 어디에 있나요 | 바깥으로 나가나요 |
| --- | --- | --- |
| 대화 기록, 첨부 복사본 | 내 컴퓨터의 데이터 폴더 | 연결한 에이전트에게 메시지가 전달돼요. 감정 판단을 켜면 일부가 TypeSafe AI로 가요 |
| 설정, 카드 위치 | 내 컴퓨터의 데이터 폴더 | 나가지 않아요 |
| 지침 파일 | 내 컴퓨터의 지침 폴더 | 에이전트가 읽고, 에이전트의 AI 서비스로 보낼 수 있어요 |
| 연결 설정 | 내 컴퓨터의 데이터 폴더 (에이전트 프로그램의 경로와 실행 인자만) | 나가지 않아요 |
| JEV 키 | macOS 키체인 또는 Windows 사용자 계정으로 암호화한 파일 | JEV를 부를 때 TypeSafe AI로만 가요 |
| 진단 기록(로그) | 내 컴퓨터의 데이터 폴더 | 나가지 않아요. 문의할 때 직접 보낼 수 있어요 |

## 컴퓨터에 남는 것

리체는 모든 데이터를 여러분의 컴퓨터에 저장해요. 리체 개발사의 서버에 대화 기록이나 설정을 올리지 않아요.

- **대화 기록:** 일상과 업무 모드의 기록을 따로 저장해요. 대화창에 첨부한 파일은 앱 전용 복사본으로 보관해요.
- **설정:** 화면, 알림, 성능, 모드별 옷차림 같은 설정과 카드의 위치, 크기, 고정핀 상태를 저장해요.
- **연결 설정:** 연결한 에이전트 프로그램의 경로와 실행 인자만 저장해요. 에이전트의 로그인 정보나 API 키는 저장하지 않아요. 로그인은 각 에이전트가 스스로 관리해요.
- **지침 파일:** 여러분이 쓴 파일이에요. 리체는 빈 파일을 만들 뿐, 내용을 쓰거나 고치지 않아요.

데이터의 정확한 위치는 [Windows 제거하기](install-windows.md#5-제거하기)와 [macOS 제거하기](install-mac.md#7-제거하기)의 표에 있어요. **리체 설정 › 일반 › 기록 폴더**의 **폴더 열기**로도 열 수 있어요.

## 바깥으로 나가는 것

### 연결한 에이전트

보낸 메시지와 첨부, 승인에 대한 답은 여러분이 연결한 에이전트 프로그램으로 가요. 에이전트는 여러분의 컴퓨터에서 실행되는 별도 프로그램이고, 답을 만들려고 메시지를 자기 AI 서비스(예: Claude Code는 Anthropic, Codex는 OpenAI)로 보낼 수 있어요. 그 처리는 각 에이전트와 서비스의 약관과 개인정보 정책을 따라요. 어떤 에이전트를 연결할지는 여러분이 정해요.

에이전트가 리체의 MCP 서버를 쓰면 리체의 표정을 바꾸거나 리체의 말풍선으로 짧게 말할 수 있어요. MCP 서버로는 대화 기록, 설정, 키를 읽을 수 없어요.

### 감정 판단 (JEV)을 켰을 때

감정 판단을 켜면 대화 한 번마다 내 메시지, 리체의 답, 바로 앞의 대화 최대 다섯 번, 리체의 성격과 기분 정보가 미국의 TypeSafe AI(`api.typesafe.ai`)로 가요. 감정 판단은 기본으로 꺼져 있고, 키를 넣어야 켜져요. 자세한 내용은 [감정 판단 (JEV)](jev.md)에 있어요.

### 리체가 보내지 않는 것

- 리체는 사용 통계나 진단 정보를 개발사로 보내지 않아요.
- 리체 캐릭터 프로그램은 대화, 설정, 화면 내용을 바깥으로 보내지 않아요.
- 리체에는 자동 업데이트가 없어서 업데이트를 확인하려고 바깥에 접속하지 않아요.

## 진단 기록 (로그)

리체는 문제를 찾을 수 있도록 데이터 폴더의 `logs` 폴더에 진단 기록을 남겨요. 연결 상태와 오류 같은 정보가 남고, 에이전트 연결 기록에는 보낸 메시지의 내용이나 에이전트의 실행 명령을 남기지 않아요. JEV 키는 어떤 기록에도 남지 않아요. 이 기록은 바깥으로 나가지 않고, 문의할 때 여러분이 직접 골라서 보낼 수 있어요.

## 알림

알림은 운영체제의 알림 기능(Windows 알림, macOS 알림 센터)으로 보여요. **내용 미리보기**가 켜져 있으면 알림에 답장의 앞부분(최대 100자)이 보여요. 다른 사람이 화면을 볼 수 있는 곳에서는 **리체 설정 › 알림 › 내용 미리보기**를 꺼 두세요. 끄면 알림에 일반적인 문장만 보여요.

## 승인 요청

에이전트가 파일을 고치거나 명령을 실행하려고 하면 리체는 대화창에서 **승인** 또는 **거절**을 기다려요. 리체는 스스로 승인하지 않고, 승인 요청 때문에 다른 창의 포커스를 빼앗지도 않아요. 에이전트가 무엇을 하려는지 읽어 보고 답해요.

## 데이터 지우기

| 지우고 싶은 것 | 방법 |
| --- | --- |
| 두 모드의 대화 기록, 첨부, 리체의 추억 | **리체 설정 › 일반 › 초기화…**를 눌러요. 확인 창이 먼저 뜨고, 지운 기록은 되돌릴 수 없어요 |
| JEV 키 | 키 창의 **키 지우기**를 눌러요 ([감정 판단 (JEV)](jev.md#키-지우기)) |
| 모든 데이터 | 리체를 끄고 데이터 폴더를 지워요 ([Windows](install-windows.md#5-제거하기), [macOS](install-mac.md#7-제거하기)) |
| 에이전트가 가진 데이터 | 그 에이전트의 안내를 따라요. 리체를 지워도 에이전트 쪽 기록은 남아요 |
| TypeSafe AI가 받은 데이터 | TypeSafe AI의 정책을 따라요 |
