# 개인정보와 데이터

[안내서 처음으로](../README.md)

이 페이지는 리체가 컴퓨터에 무엇을 남기고, 어떤 때 바깥에 연결하는지 설명해요. Gujo 계정과 스토어의 개인정보 처리는 [Gujo 개인정보 처리방침](https://account.gujo.io/ko/privacy)을 따라요.

## 한눈에 보기

- 대화 기록과 설정은 여러분의 컴퓨터에 저장해요. 판매자의 서버에 올리지 않아요.
- 리체는 사용 통계 수집(텔레메트리)이나 오류 보고서 자동 전송을 하지 않아요.
- 판매용 리체는 외부 연결을 받는 포트를 열지 않아요. 에이전트와의 연결도 로컬 프로그램 사이에서 이뤄져요.
- JEV는 선택 기능이에요. 여러분이 켜고 키를 넣었을 때만 미국의 TypeSafe AI로 판단에 필요한 정보를 보내요.
- 새 버전 알림은 GitHub의 작은 파일을 확인해요. 이때 GitHub가 IP 주소를 알 수 있고, 원하지 않으면 끌 수 있어요.

## 컴퓨터에 남는 것

| 정보 | 저장하는 내용 |
| --- | --- |
| 대화 기록 | 일상·업무 대화 기록과 첨부 파일의 앱 전용 복사본 |
| 설정과 카드 위치 | 화면, 알림, 성능, 모드별 옷차림, 위치·크기·고정핀 상태 |
| 연결 설정 | 에이전트 프로그램의 경로와 실행 인자. 에이전트의 로그인 정보나 API 키는 리체가 저장하지 않아요 |
| 지침 파일 | 여러분이 쓰는 성격과 말투 등의 지침. 에이전트가 읽을 수 있어요 |
| JEV 키 | macOS 로그인 키체인 또는 Windows 사용자 계정으로 암호화한 파일 |
| 진단 기록과 오류 보고서 | 연결 상태, 오류 등 문제를 찾는 데 필요한 로컬 기록 |

정확한 위치와 지우는 방법은 [Windows 제거하기](install-windows.md#5-제거하기), [macOS 제거하기](install-mac.md#7-제거하기)에 있어요. **리체 설정 › 일반 › 기록 폴더 › 폴더 열기**로 데이터 폴더를 열 수도 있어요.

## 바깥에 연결하는 경우

### 여러분이 연결한 에이전트

Claude Code, Codex, OpenClaw, Hermes 등은 **여러분의 컴퓨터에서 여러분이 설치하고 실행하는 별도 프로그램**이에요. 리체는 표준 입출력으로 메시지, 첨부, 승인에 대한 답을 전달해요. 에이전트는 답을 만들려고 자기 AI 서비스로 내용을 보낼 수 있어요. 에이전트를 설치하거나 `npx`로 실행하면 해당 프로그램을 내려받는 연결도 생길 수 있어요.

별도로 연결한 `brain` CLI나 리체 브릿지도 같은 원칙을 따라요. 이 프로그램들의 외부 연결과 데이터 처리에는 각 프로그램과 서비스의 약관·정책이 적용돼요. 리체를 지워도 에이전트와 그 기록은 남아요.

리체의 MCP 연결은 네트워크 서버가 아니라 로컬 표준 입출력을 써요. 에이전트는 이를 통해 표정과 동작을 바꾸거나 짧은 말을 보여 줄 수 있지만, 대화 기록·설정·키를 읽을 수는 없어요.

### 감정 판단 (JEV)을 켰을 때

여러분이 감정 판단을 켜고 키를 저장하면 `liche-judge`가 **미국의 TypeSafe AI**(`https://api.typesafe.ai/v1/systemone`)에 HTTPS로 연결해요. 키를 저장할 때 확인용으로 한 번 호출하고, 켜 둔 동안 판단할 대화마다 호출해요.

보내는 정보는 내 메시지, 리체의 답과 말풍선, 바로 앞 대화 최대 다섯 번, 리체의 성격·기분·작업 상태예요. 기본으로 꺼져 있고, 끄거나 키가 없으면 보내지 않아요. 요금, 전송 항목과 끄는 방법은 [감정 판단 (JEV)](jev.md)에 있어요.

### 새 버전을 확인할 때

새 버전 알림이 켜져 있으면 하루에 한 번 GitHub의 `raw.githubusercontent.com`에서 [작은 버전 안내 파일](https://raw.githubusercontent.com/gujo-io/agent-liche-docs/main/latest.json)을 가져와요. **리체 정보**를 열 때도 최대 10분에 한 번 확인해요.

이 연결로 **GitHub에 IP 주소가 전달돼요.** 대화 내용, 계정 정보, 기기 식별자, 쿠키는 보내지 않아요. 앱을 자동으로 내려받거나 설치하지도 않아요. **리체 설정 › 리체 정보**에서 새 버전 알림 스위치를 끄면 이 연결을 하지 않아요. 스위치의 정확한 이름은 **(확인 중)**이에요.

### 링크를 눌렀을 때

대화창이나 설정에서 웹 링크를 누르면 기본 브라우저가 그 페이지를 열어요. 해당 사이트는 브라우저의 일반적인 연결 정보와, 브라우저에 이미 로그인돼 있다면 그 세션을 받을 수 있어요.

### 별도 창의 파일 분류 기능을 직접 설정했을 때

일반적인 카드 대화와는 별개로, 예전 독립 창의 파일 분류 기능을 쓰는 경우가 있어요. 여러분이 환경 변수에 JEV 서버 주소와 키를 둘 다 설정하고 그 창에 파일을 놓았을 때만, 설정한 서버의 `/v1/systemone`으로 HTTPS 요청을 보내요. 기본 서버 주소는 없어요. 이 기능은 `curl` 명령의 인자로 키를 넘겨서, 같은 컴퓨터의 다른 프로그램에 키가 보일 수 있어요. 일반적인 에이전트 연결과 선택 JEV 키 창은 이 방식을 쓰지 않아요.

### 연결하지 않는 것

캐릭터를 그리는 리체 프로그램은 네트워크에 연결하지 않아요. 판매용 패키지는 사용 통계 수집 기능과 외부 연결을 받는 기능을 끄고 배포해요. 오류가 나면 로컬 파일이 남을 수 있지만 오류 보고서를 자동으로 전송하는 프로그램은 포함하지 않아요.

## 진단 파일 만들기

**리체 설정 › 리체 정보 › 진단 파일 만들기**를 누르면 바탕 화면에 고객지원용 zip 파일이 생겨요. 파일을 만들기만 하며, 자동으로 전송하지 않아요.

- **들어 있는 것:** 대화창과 캐릭터 프로그램의 진단 기록, 최근 오류 보고서, 설정 파일, 앱 버전·운영체제·화면 정보, 수집에서 빠진 파일 목록.
- **넣지 않는 것:** 대화 기록 파일, 첨부 파일, JEV 키 파일, 메모리 덤프.
- **가리는 것:** 기록에 남은 대화 글, 키와 토큰, 경로에 들어 있는 사용자 이름. 대화 글은 글자 수만 남겨요.

보내기 전에 zip 파일을 열어 내용을 확인해 주세요. 보내고 싶지 않은 파일은 빼도 돼요. 자세한 문의 방법은 [문제 해결](troubleshooting.md#문의할-때-알려-주시면-좋은-것)에 있어요.

## 알림과 승인 요청

**내용 미리보기**가 켜져 있으면 운영체제 알림에 답장의 앞부분(최대 100자)이 보여요. 다른 사람이 화면을 볼 수 있다면 **리체 설정 › 알림 › 내용 미리보기**를 꺼 두세요.

에이전트가 도구 사용 승인을 요청하면 리체는 **승인**이나 **거절**을 기다려요. 스스로 승인하지 않고 다른 창의 포커스를 빼앗지 않아요. 요청 내용을 확인한 뒤 답해요.
