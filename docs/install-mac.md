# macOS 설치와 제거 (예정)

[안내서 처음으로](../README.md)

> macOS 판은 아직 준비 중이에요 (예정). 나오면 지금의 Agent Liche 상품에 함께 들어가고, 업데이트 기간 안이면 추가 요금 없이 받을 수 있어요. 이 페이지는 준비 중인 macOS 판을 기준으로 써서 출시 때 조금 바뀔 수 있어요.

## 필요한 것

- Apple Silicon(M1 이상) Mac. Intel Mac은 지원하지 않아요.
- macOS 14 이상. 실제로 확인한 버전은 macOS 26과 27이에요 (14부터 25까지는 확인 중).
- 리체와 연결할 AI 에이전트 ([에이전트 연결](agents.md) 참고)

## 1. 내려받기

Gujo 스토어에 로그인한 뒤 라이브러리에서 macOS용 파일을 내려받아요. (확인 중: macOS 판의 배포 방식과 Gujo Cloud Apps 지원 여부)

내려받은 zip 파일을 더블클릭하면 같은 폴더에 `Agent Liche.app`이 생겨요.

## 2. 응용 프로그램 폴더로 옮기기

1. Finder에서 `Agent Liche.app`을 왼쪽 사이드바의 **응용 프로그램**으로 끌어다 놓아요.
2. 다운로드 폴더에 남은 zip 파일은 지워도 돼요.

응용 프로그램 폴더가 아닌 곳에서도 실행되지만, 업데이트할 때 같은 자리에서 바꾸기 쉽도록 응용 프로그램 폴더에 두기를 권해요.

## 3. 처음 열기

1. 응용 프로그램 폴더에서 **Agent Liche**를 더블클릭해요.
2. 인터넷에서 내려받은 앱이라는 확인 창이 뜨면 **열기**를 눌러요.
3. 화면 전체를 쓰는 첫 실행 안내가 열려요. [처음 실행](first-run.md)을 따라 에이전트를 연결해요.

macOS 판은 Apple의 Developer ID로 서명하고 Apple의 공증(notarization)을 받아 배포할 예정이에요 (예정). 그래서 보통은 위의 확인 창 하나만 떠요.

### "확인할 수 없습니다"라는 창이 뜰 때

Apple이 악성 코드를 확인할 수 없다는 창이 뜨고 열리지 않으면 아래처럼 해요.

1. 창에서 **완료**를 눌러 닫아요.
2. **시스템 설정 › 개인정보 보호 및 보안**을 열어요.
3. 아래쪽 보안 항목에 Agent Liche를 막았다는 줄이 보이면 **그래도 열기**를 눌러요.
4. Mac 로그인 암호를 넣고, 다시 뜨는 창에서 **열기**를 눌러요.

이 창은 스토어에서 받은 정식 파일이 아닐 때도 뜰 수 있어요. 파일을 받은 곳이 Gujo 스토어인지 먼저 확인해요.

## 4. macOS가 묻는 권한

리체는 시작할 때 문서 폴더, 화면 기록, 손쉬운 사용, 입력 모니터링 권한을 묻지 않아요. 아래 질문은 필요한 순간에만 떠요.

| 질문 | 언제 뜨나요 | 어떻게 답하나요 |
| --- | --- | --- |
| "Agent Liche"의 알림 허용 | 리체가 처음 알림을 보낼 때 | 답장 알림을 받으려면 **허용**을 눌러요. 나중에 **시스템 설정 › 알림 › Agent Liche**에서 바꿀 수 있어요 |
| `liche-judge`의 키체인 사용 | 감정 판단(JEV) 키를 저장하거나 읽을 때, 업데이트 직후 한 번 뜰 수 있어요 | **허용** 또는 **항상 허용**을 눌러요. **거부**하면 키를 다시 저장할 때까지 감정 판단이 동작하지 않아요 |
| 연결한 에이전트가 묻는 권한 (예: 문서 폴더) | 에이전트가 그 폴더나 기능을 처음 쓸 때 | 에이전트의 질문이에요. 답하기 전까지 에이전트가 멈춰 있을 수 있으니 먼저 답해요 |

## 5. 로그인할 때 자동으로 켜기

macOS에서는 리체가 로그인 항목을 스스로 만들지 않아요. 로그인할 때 켜려면 직접 추가해요.

1. **시스템 설정 › 일반 › 로그인 항목 및 확장 프로그램**을 열어요.
2. **로그인 시 열기** 아래의 **+**를 누르고 응용 프로그램 폴더의 **Agent Liche**를 골라요.

## 6. 끄기

- Dock에서 Agent Liche 아이콘을 오른쪽 클릭하고 **종료**를 골라요.
- Agent Liche가 앞에 있는 앱일 때 `⌘Q`를 눌러도 돼요.
- 대화창은 리체가 꺼지면 함께 꺼져요.

## 7. 제거하기

1. **감정 판단 키 지우기 (선택):** JEV 키를 넣었다면 리체가 켜져 있을 때 키 창에서 **키 지우기**를 눌러요. 리체를 먼저 지웠다면 아래 "키체인 항목 지우기"를 따라 해요.
2. **리체 끄기:** 위 "끄기"대로 리체를 꺼요.
3. **앱 지우기:** 응용 프로그램 폴더의 `Agent Liche.app`을 휴지통으로 옮겨요.
4. **데이터 폴더 지우기:** Finder에서 `⌘⇧G`를 누르고 아래 경로를 하나씩 넣어 열고 지워요. 대화 기록과 설정을 남기고 싶으면 먼저 다른 곳에 복사해 두세요.
5. 로그인 항목에 추가했다면 **시스템 설정 › 일반 › 로그인 항목 및 확장 프로그램**에서도 지워요.

| 위치 | 들어 있는 것 |
| --- | --- |
| `~/Library/Application Support/LicheWidget` | 두 모드의 대화 기록과 첨부 복사본, 연결 설정, 화면·알림·성능 설정, 위젯 설정 파일 `settings.json`, 감정 판단 상태, 진단 기록(`logs`) |
| `~/Library/Application Support/Epic/LicheWidget` | 카드 위치와 크기, 고정핀 상태 |
| `~/Liche` | 여러분이 쓴 지침 파일(`common.md`, `daily`, `developer`)과 에이전트가 모드별로 일하는 폴더. 직접 만든 파일이 들어 있을 수 있으니 확인한 뒤 지워요 |
| 로그인 키체인의 `com.agentliche.jev` 항목 | 감정 판단(JEV) 키 |

macOS와 언리얼 엔진이 앱마다 만드는 아래 항목도 있을 수 있어요. 있으면 함께 지워도 돼요. (확인 중: 실제로 생기는 항목)

- `~/Library/Application Support/Epic/a001_Cartoon` (엔진의 기록 폴더)
- `~/Library/Caches/com.agentliche.Liche`
- `~/Library/Preferences/com.agentliche.Liche.plist`
- `~/Library/Saved Application State/com.agentliche.Liche.savedState`

### 키체인 항목 지우기

1. **키체인 접근** 앱을 열어요 (Spotlight에서 "키체인 접근" 검색).
2. 왼쪽에서 **로그인** 키체인을 골라요.
3. 오른쪽 위 검색 칸에 `com.agentliche.jev`를 넣어요.
4. 나온 항목을 오른쪽 클릭하고 **삭제**를 골라요.

### 터미널로 한 번에 지우기

리체를 끈 뒤 터미널에서 아래 명령을 실행해요. 지침 폴더(`~/Liche`)는 직접 쓴 파일이 있을 수 있어서 명령에 넣지 않았어요.

```bash
rm -rf "$HOME/Library/Application Support/LicheWidget" "$HOME/Library/Application Support/Epic/LicheWidget"
security delete-generic-password -s com.agentliche.jev -a jev
```

연결한 에이전트(Claude Code, Codex, OpenClaw, Hermes 등)는 리체와 따로 설치한 프로그램이에요. 리체를 지워도 에이전트와 그 설정은 남아 있어요.
