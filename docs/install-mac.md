# macOS 설치와 제거

[안내서 처음으로](../README.md)

> 0.2.0 출시 준비본이에요. 최종 판매 파일의 서명·공증과 설치 확인은 출시 전에 마쳐야 해요.

## 필요한 것

- **Apple Silicon(M1 이상) Mac만 지원해요. Intel Mac은 지원하지 않아요.**
- macOS 14 이상. 실제로 확인한 버전은 macOS 26과 27이며, 14부터 25까지는 확인 중이에요 (확인 중).
- 최소 메모리·성능 사양은 저사양 Mac 측정 전이에요 (확인 중).
- 파일을 내려받고 압축을 풀 저장 공간. 최종 용량은 확인 중이에요 (확인 중).
- 별도로 설치하고 로그인한 AI 에이전트. [에이전트 연결](agents.md)을 참고해요.

## 1. 내려받기

Gujo 스토어에 로그인한 뒤 라이브러리에서 macOS용 zip 파일을 내려받아요. 더블클릭해 풀면 **`Agent Liche.app`**이 생겨요. 같은 상품 구매에 Windows와 macOS 파일이 모두 포함돼요. macOS용 Gujo Cloud Apps 설치 지원은 확인 중이에요 (확인 중).

## 2. 응용 프로그램 폴더로 옮기기

Finder에서 `Agent Liche.app`을 **응용 프로그램**으로 끌어다 놓아요. 자동 시작을 쓰거나 업데이트할 때 같은 위치에서 바꾸기 쉬워요. 옮긴 뒤 다운로드 폴더의 zip 파일은 지워도 돼요.

## 3. 처음 열기

1. 응용 프로그램 폴더에서 **Agent Liche**를 더블클릭해요.
2. 인터넷에서 내려받은 앱이라는 확인 창이 뜨면 파일 출처를 확인하고 **열기**를 눌러요.
3. [처음 실행](first-run.md)에 따라 에이전트를 연결해요. 리체의 대답은 연결한 AI 에이전트가 만들어요.

0.2.0 최종 판매 파일의 Developer ID 서명과 Apple 공증 결과는 확인 중이에요 (확인 중). 이전 시험 빌드의 결과를 최종 파일의 결과로 보지는 않아요.

### "확인할 수 없습니다"라는 창이 뜰 때

Gujo 스토어에서 받은 정식 파일이 맞는지 먼저 확인해요. Apple이 확인할 수 없다는 경고나 손상·악성 코드 경고가 나오면 창의 문장과 버전을 고객지원에 알려 주세요. 보안 기능을 끄거나 출처를 모르는 파일을 강제로 열지 마세요.

## 4. macOS가 묻는 권한

리체 자체는 시작할 때 화면 기록·손쉬운 사용·입력 모니터링 권한을 요구하지 않아요.

| 질문 | 언제와 어떻게 답하나요 |
| --- | --- |
| Agent Liche의 알림 | 처음 알림을 보낼 때 물어요. 알림을 받으려면 **허용**해요. 나중에 **시스템 설정 › 알림 › Agent Liche**에서 바꿔요 |
| `liche-judge`의 키체인 사용 | JEV 키 저장·읽기나 업데이트 뒤에 물을 수 있어요. 요청한 프로그램을 확인하고 **허용** 또는 **항상 허용**을 골라요. 거부했다면 키를 다시 저장해요 |
| 연결한 에이전트의 권한 | 문서 폴더 등 에이전트가 필요한 권한은 그 프로그램의 요청이에요. 요청 내용과 프로그램을 확인한 뒤 답해요 |

## 5. 로그인할 때 자동으로 켜기

1. **리체 설정 › 일반 › 컴퓨터를 켜면 리체도 시작**을 켜요.
2. 로그인 항목에서 허용해야 한다는 안내가 보이면 **시스템 설정 열기 ›**를 누르고 **일반 › 로그인 항목**에서 Agent Liche를 허용해요. macOS 버전에 따라 페이지 이름은 **로그인 항목 및 확장 프로그램**이에요.
3. **macOS 로그인 항목에 켜져 있어요.**가 보이면 끝이에요.

**macOS가 이 앱을 찾지 못했어요.**가 보이면 `Agent Liche.app`을 응용 프로그램 폴더로 옮긴 뒤 스위치를 껐다가 다시 켜요. 자동 시작을 끄려면 같은 스위치를 꺼요.

## 6. 끄기

Dock의 Agent Liche 아이콘을 오른쪽 클릭해 **종료**를 골라요. Agent Liche가 앞에 있을 때 `⌘Q`를 눌러도 돼요. 대화창도 함께 꺼져요.

## 7. 제거하기

1. 리체가 켜져 있을 때 **컴퓨터를 켜면 리체도 시작**을 꺼요.
2. JEV를 썼다면 키 창에서 **키 지우기**를 눌러요. 앱을 먼저 지웠다면 아래 키체인 안내를 따라요.
3. 리체를 끄고 응용 프로그램 폴더의 `Agent Liche.app`을 휴지통으로 옮겨요.
4. 필요한 파일을 먼저 복사한 뒤 Finder에서 `⌘⇧G`로 아래 경로를 하나씩 열어 지워요. 폴더가 없다면 건너뛰어요. **지운 대화와 직접 만든 파일은 되돌릴 수 없어요.**
5. 로그인 항목이 남아 있다면 **시스템 설정 › 일반 › 로그인 항목**에서도 지워요.

| 위치 | 들어 있는 것 |
| --- | --- |
| `~/Library/Application Support/LicheWidget` | 대화 기록·첨부, 연결·화면·알림·성능 설정, 위젯 설정, JEV 상태, 진단 기록 |
| `~/Library/Application Support/Epic/LicheWidget` | 카드 위치·크기·고정핀 상태 |
| `~/Liche` | 공통·모드별 지침과 에이전트 작업 파일. 직접 만든 파일을 먼저 확인해요 |
| `~/Library/Application Support/Epic/AgentLiche/Saved` | 엔진 기록·임시 파일이 남아 있을 수 있어요 |
| `~/Library/Logs/AgentLiche` | 엔진 로그가 남아 있을 수 있어요 |
| 로그인 키체인의 `com.agentliche.jev` | JEV 키 |

macOS가 별도로 만드는 캐시·설정·창 복원 파일의 실제 생성 여부는 확인 중이에요 (확인 중): `~/Library/Caches/com.agentliche.Liche`, `~/Library/Preferences/com.agentliche.Liche.plist`, `~/Library/Saved Application State/com.agentliche.Liche.savedState`.

### 키체인 항목 지우기

1. Spotlight에서 **키체인 접근**을 검색해 열어요.
2. **로그인** 키체인을 골라 `com.agentliche.jev`를 검색해요.
3. 해당 항목을 오른쪽 클릭하고 **삭제**를 골라요.

이전 버전의 폴더는 [업데이트 안내](updates.md#이전-폴더-정리하기)에 따라 따로 정리해요. 연결한 에이전트는 리체와 별도여서 앱을 지워도 그 프로그램과 데이터는 남아요.
