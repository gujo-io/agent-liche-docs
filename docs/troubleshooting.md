## 알려진 문제 (0.2.0)

| 플랫폼 | 문제 | 해결 또는 우회 |
| --- | --- | --- |
| Windows | 코드 서명이 없어서 처음 실행할 때 SmartScreen의 "Windows의 PC 보호" 창이 떠요 | **추가 정보 › 실행**을 눌러요 ([안내](install-windows.md#windows의-pc-보호-창이-뜰-때-smartscreen)). 코드 서명은 다음 업데이트에서 넣어요 |
| Windows | 디스플레이 배율이 125 %나 150 %일 때, 리체 설정 같은 창에서 글 입력칸의 오른쪽 클릭 메뉴(복사·붙여 넣기)와 마우스를 올리면 뜨는 도움말이 100 % 크기로 작게 그려져요 | 동작에는 문제가 없어요. 창 자체와 글자는 모니터 배율대로 그려져요. 다음 업데이트에서 고칠 예정이에요 |
| Windows | 스마트 앱 컨트롤이 켜진 PC에서는 서명이 없는 0.2.0이 **실행** 단추 없이 막힐 수 있어요 | 고객지원에 알려 주세요 |

## 설치와 실행

### Windows에서 "Windows의 PC 보호" 창이 떠요

0.2.0 Windows 판은 코드 서명이 없어서, 처음 실행할 때 SmartScreen이 게시자를 **알 수 없는 게시자**로 보여 줘요. Gujo 스토어에서 받은 파일인지 확인한 뒤 **추가 정보**를 누르고 **실행**을 눌러요. 받은 파일의 SHA-256 값을 확인하는 방법과 자세한 순서는 [Windows 설치](install-windows.md#windows의-pc-보호-창이-뜰-때-smartscreen)에 있어요. 출처를 모르는 파일이나 Microsoft Defender가 위험하다고 탐지한 파일은 실행하지 마세요.

### Windows에서 방화벽 창이 떠요

판매용 리체는 외부 연결을 받는 포트를 열지 않아 방화벽 허용이 필요하지 않아요. 리체 캐릭터 프로그램의 수신 연결을 묻는다면 허용하지 말고 파일 출처와 버전을 확인해 고객지원에 알려 주세요. 별도로 설치한 에이전트가 묻는 창은 그 프로그램의 안내를 확인해요.

### macOS에서 앱이 열리지 않아요

0.2.0 macOS 판은 Developer ID로 서명하고 Apple 공증을 받았어요. 처음 열 때는 인터넷에서 받은 앱을 열지 묻는 창에서 **열기**만 누르면 돼요. 개발자를 확인할 수 없다거나 앱이 손상되었다는 경고가 뜬다면 받은 파일이 다를 수 있어요. 앱 출처가 Gujo 스토어인지 확인하고, 경고의 문장을 고객지원에 알려 주세요. [macOS 설치](install-mac.md#gatekeeper-확인-창)를 참고해요.

Intel Mac에서는 열리지 않아요. 0.2.0은 Apple Silicon Mac만 지원해요.

### macOS에서 권한을 물어요

리체가 직접 묻는 것은 알림과, 감정 판단을 쓸 때의 키체인뿐이에요. 문서 폴더처럼 다른 권한을 묻는 창은 대개 연결한 에이전트가 띄운 거예요. 에이전트는 답을 받을 때까지 멈춰 있으니 먼저 답해요. 어떤 창이 왜 뜨는지는 [macOS 설치](install-mac.md#4-macos가-묻는-권한)에 있어요.

### Windows에서 새 버전을 켰는데 리체가 둘이에요

이전 버전이 아직 켜져 있으면 새 버전과 함께 뜰 수 있어요. 두 리체를 모두 끈 뒤 새 버전만 켜요. 업데이트하기 전에는 이전 버전을 먼저 꺼 두세요.

## 연결

### 대화창에 "리체가 아직 바깥과 연결되지 않았어요"가 보여요

아직 에이전트를 연결하지 않았어요. Windows는 **연결 설정**, macOS는 **리체 연결하기**를 눌러 에이전트를 골라요. [에이전트 연결](agents.md)을 봐요.

### 리체가 계속 졸아요

리체는 에이전트와 연결되지 않았을 때만 졸아요. 연결 카드(**리체 설정**의 사이드바 맨 위)에서 상태를 확인해요. 에이전트가 꺼졌거나 응답하지 않으면 [에이전트 연결](agents.md#응답하지-않아요가-뜰-때)을 따라 해요. 연결되면 리체가 스스로 깨어나요.

### "(에이전트)가 응답하지 않아요"가 떠요

에이전트가 45초 안에 답하지 않았다는 뜻이에요. 권한 확인 창, 에이전트의 로그인, 설치 위치를 차례로 확인해요. 리체는 잠시 뒤 스스로 다시 연결해 봐요. 자세한 순서는 [에이전트 연결](agents.md#응답하지-않아요가-뜰-때)에 있어요.

### "연결을 저장한 지 30초가 지났어요"가 떠요

에이전트가 로그인이나 첫 설정을 기다리고 있을 가능성이 커요. 터미널에서 그 에이전트를 한 번 실행해 설정을 끝낸 뒤 다시 골라요.

### 연결 카드에 "리체 대화 꺼짐"이 보여요

대화창 프로그램이 꺼져 있다는 뜻이에요. 리체 캐릭터는 대화창 프로그램이 꺼지면 다시 띄우지만, 그래도 돌아오지 않으면 리체를 완전히 껐다가 다시 켜요.

### 설치한 에이전트를 리체가 찾지 못해요 (macOS)

리체는 PATH와 `/opt/homebrew/bin`, `/usr/local/bin`, `~/.local/bin`에서 에이전트를 찾아요. nvm처럼 다른 곳에 설치했다면 첫 실행 안내의 **에이전트로 연결하기**에서 **복사**를 눌러, 복사한 글을 에이전트에게 붙여 넣어요.

### "이 연결은 아직 모드별 대화를 지원하지 않아요"가 보여요

연결한 에이전트가 모드마다 따로 대화를 열지 못하는 경우예요. 두 모드의 기록은 따로 남지만, 답은 한 번에 한 모드에서만 기다릴 수 있어요. 다른 모드에서 보내면 안내가 뜨고 쓰던 글은 남아 있어요.

## 대화

### 메시지를 보낼 수 없어요

같은 모드에서 답을 기다리는 동안에는 새 메시지를 보낼 수 없어요. 답이 끝나기를 기다리거나 **■ 중지**를 눌러요. 쓰던 글은 입력칸에 그대로 남아요. 다른 모드로 바꾸면 그 모드에서는 보낼 수 있어요.

### 답이 오다가 "응답이 없어요"가 떴어요

에이전트가 도구를 쓰지 않는 동안 2분(120초) 넘게 아무 소식이 없었다는 뜻이에요. 에이전트가 아직 생각하고 있을 수 있으니 잠시 뒤 다시 물어봐요. 자주 그러면 에이전트의 상태를 확인해요.

에이전트가 도구를 쓰는 동안에는 2분 제한이 없어요. 대화창에 "작업 중이에요 · 3분 12초"처럼 보이는 동안은 기다려요. [답을 기다리는 시간](first-run.md#답을-기다리는-시간)을 참고해요.

### "작업이 30분 넘게 아무 소식이 없어서 기다리기를 멈췄어요"가 떴어요

에이전트가 도구를 쓰는 중에 30분 동안 진행 소식이 한 번도 오지 않았다는 뜻이에요. 에이전트의 터미널이나 작업 결과를 확인해요. 소식 없이 30분 넘게 걸리는 일을 자주 맡긴다면 환경 변수 `LICHE_INPUT_TOOL_TIMEOUT_MINUTES`로 시간을 늘릴 수 있어요(2~1440분). 방법은 [답을 기다리는 시간](first-run.md#답을-기다리는-시간)에 있어요.

### 승인 요청이 사라졌어요

**■ 중지**를 누르거나 연결이 끊기면 남은 승인 요청은 모두 취소돼요. 에이전트에게 다시 부탁해요.

### 리체의 표정이 대화와 잘 맞지 않아요

감정 판단(JEV)이 꺼져 있으면 리체는 정해진 규칙대로만 반응해요. 대화에 맞는 표정을 원하면 [감정 판단 (JEV)](jev.md)을 켜요.

### 지운 지침 파일이 다시 생겼어요

`common.md`, `daily.md`, `developer.md`는 없으면 리체가 기본 지침으로 다시 만들어요. 지침을 끄고 싶다면 파일을 지우지 말고 내용을 비워 두세요. 빈 파일은 리체가 다시 채우지 않아요. 자세한 규칙은 [지침 파일](guides.md#기본-지침)에 있어요.

### 일상 모드에서 일을 부탁했더니 업무 모드를 권해요

기본 지침에서 리체는 모드에 맞지 않는 부탁을 받으면 다른 모드를 한 번 권해요. 그래도 해 달라고 하면 그 모드에서 그대로 해요.

## 화면과 창

### 카드가 화면 밖으로 나가서 잡을 수 없어요

- **리체 설정 › 창 › 카드를 화면 가운데로**의 **옮기기**를 눌러요. 지금 크기 그대로 포인터가 있는 화면 가운데로 옮겨져요.
- macOS: Dock의 Agent Liche 아이콘을 오른쪽 클릭해 **카드를 화면 가운데로**를 고르거나, Agent Liche가 앞에 있을 때 `⌥⌘L`을 눌러요.
- Windows: 작업 표시줄의 리체 단추를 Shift를 누른 채 오른쪽 클릭하거나, 리체를 누른 뒤 `Alt+Space`를 눌러 창 메뉴의 **카드를 화면 가운데로**를 골라요.

리체는 끌기를 놓을 때, 화면 구성이 바뀔 때, 그리고 1초마다 유리 카드와 아이콘이 화면 안에 있는지 확인하고 벗어나 있으면 가장 가까운 자리로 옮겨요. 모니터를 뺐다면 주 화면의 같은 자리쯤으로 옮겨요. 유리 위로 나온 리체의 머리는 화면 밖에 있어도 그대로 둬요.

### 아이콘이 열리지 않아요

카드 오른쪽 위의 **⋯** 위에 포인터를 잠깐 올려 두면 아이콘이 펼쳐져요. **⋯**를 눌러도 아무것도 열리지 않는 것이 정상이에요.

### 카드가 너무 크거나 작아요

유리 카드의 둥근 모서리 안쪽을 끌어 크기를 바꿔요. 놓은 뒤 잠깐 보이는 **100%로**를 누르면 기본 크기로 돌아와요.

### 대화 글자가 너무 작거나 커요

**리체 설정 › 화면 › 글자 크기**에서 바꿔요. 카드 크기를 바꿔도 글자 크기는 그대로예요.

### 밝기를 바꿔도 대화창 색이 그대로예요

색 조합이 **직접**이고 라이트와 다크의 직접 색이 같으면 밝기를 바꿔도 색이 바뀌지 않아요. 다른 색 조합을 고르거나, 밝기를 바꾼 뒤 **직접 고르기 ›**에서 그 밝기의 색을 정해요.

## 성능과 배터리

### CPU나 GPU를 많이 써요, 배터리가 빨리 줄어요

리체는 3D 캐릭터를 계속 그려서 CPU와 GPU를 꾸준히 써요. 아래 순서로 줄여요.

1. **리체 설정 › 성능 › 성능 프로필**을 **절약**으로 바꿔요.
2. **최대 프레임**을 낮춰요. 15가 가장 가벼워요.
3. **가려지면 쉬기**를 켜 두세요. Windows와 macOS에서 리체가 다른 창에 완전히 가려지는 등 화면에 보이지 않을 때 그리기를 쉬어요.
4. Windows에서 **선명도**를 **보통**으로 바꾸면 GPU를 훨씬 덜 써요. 리체를 다시 시작해야 적용돼요.

리체는 20초 넘게 아무 변화가 없으면 스스로 **가만히 있을 때 프레임**까지 낮춰 그려요. **성능** 페이지 아래쪽 **지금 리체가 쓰는 양**에서 실제 사용량을 확인할 수 있어요.

## 알림

### 알림이 오지 않아요

1. **리체 설정 › 알림 › 알림 받기**가 켜져 있는지 확인해요.
2. 페이지 위쪽에 운영체제 알림이 꺼져 있다는 경고가 있으면 그 단추로 설정을 열어 Agent Liche의 알림을 켜요.
3. **테스트 알림**의 **보내기**로 시험해 봐요.
4. 대화창을 보고 있을 때는 지금 보는 대화의 알림이 조용해요. 늘 받으려면 **리체를 보고 있을 때도 알림**을 켜요.
5. Windows 11의 **방해 금지**가 "게임을 플레이할 때" 자동으로 켜지면, Windows가 리체를 게임으로 여겨 배너를 숨길 수 있어요. 이때 알림은 알림 센터에 남아요. **설정 › 시스템 › 알림 › 자동으로 방해 금지 켜기**에서 그 항목을 꺼요.

## 업데이트 뒤

### 업데이트했더니 대화 기록과 설정이 없어졌어요

이름을 Lize에서 Liche로 바꾼 업데이트는 처음 설치처럼 새로 시작해요. 이전 기록과 설정은 지워지지 않고 이전 폴더(`LizeWidget`, `Lize`)에 그대로 남아 있어요. 다만 새 버전은 그 폴더를 읽지 않아요. 지침 파일이 필요하면 이전 지침 폴더에서 새 지침 폴더로 직접 복사해요. 자세한 내용은 [업데이트](updates.md)에 있어요.

## 문의할 때 알려 주시면 좋은 것

- 운영체제와 버전 (예: Windows 11 24H2, macOS 26.5)
- **리체 설정 › 리체 정보**의 버전 줄 (예: `버전 0.2.0 (2026.11.02 · a2b5fea)`)
- 연결한 에이전트와 그 버전
- 무엇을 했을 때 무엇이 보였는지, 화면에 뜬 문장 그대로
- 가능하면 **리체 설정 › 리체 정보 › 진단 파일 만들기**로 만든 바탕 화면의 `Liche-diagnostics-날짜-시각.zip`을 첨부해요. 로그·설정·최근 오류 보고서·버전과 화면 정보가 들어가요. 대화 기록·첨부·JEV 키 파일·메모리 덤프는 넣지 않고, 로그의 대화 글·키·토큰·사용자 경로를 가려요. 자동 전송하지 않으니 **직접 열어 확인한 뒤** 보내 주세요.
- 진단 파일을 만들 수 없으면 **리체 설정 › 일반 › 기록 폴더 › 폴더 열기**로 연 폴더의 `logs` 안 `input.log`를 확인해요. 이 원본 로그에는 진단 zip의 가림 처리가 적용되지 않으니 민감한 내용을 직접 확인하고 보내 주세요.
