# 리체 설정

[안내서 처음으로](../README.md) · [English](../en/docs/settings.md)

카드 오른쪽 위의 **⋯**에 포인터를 올리고 **설정**(톱니바퀴)을 누르면 **리체 설정** 창이 열려요. 다시 누르거나 창의 닫기 단추를 누르면 닫혀요. 0.2.0은 0.1.0과 설정 창 구성이 달라요.

## 창의 구성

- **왼쪽 사이드바:** 맨 위에 **설정 검색**이 있고, 그 아래에 연결 카드와 페이지 목록이 있어요. 페이지 이름 아래에는 지금 값이 한 줄로 보여요.
- **오른쪽 본문:** 고른 페이지의 항목이 카드로 나와요. 켜고 끄는 항목은 스위치, 하나를 고르는 항목은 칩, 창을 여는 항목은 단추예요.
- **설정 검색:** 낱말을 넣으면 맞는 항목과 그 위치(예: `모드 > 업무 > 옷차림`)를 보여 줘요. "의상", "다크 모드", "고정핀", "알람", "글꼴" 같은 비슷한 말로도 찾아져요.

"(Windows)"라고 적은 항목은 Windows에만 있어요. macOS에서는 아직 지원하지 않아 보이지 않아요.

## 연결

사이드바 맨 위 카드에 연결한 에이전트와 상태가 보여요(예: `Hermes · 연결됨`, `OpenClaw · 다시 시도 중 (3/8)`). 상태는 **연결 중**, **다시 시도 중**, **해결 필요**, **연결됨** 가운데 하나예요. 카드를 누르면 연결 페이지가 열려요.

| 항목 | 설명 |
| --- | --- |
| 연결 설정 열기 | 에이전트를 고르는 화면을 열어요. macOS는 첫 실행 안내의 연결 단계, Windows는 **연결 설정** 창이 열려요. 연결에 문제가 있으면 에이전트 이름 아래에 그 이유가 한 줄로 보여요. 이유별로 할 일은 [연결이 안 될 때](troubleshooting.md#연결이-안-될-때)에 있어요 |
| 선택 기능 › 감정 판단 (JEV) · 선택 | 대화를 보고 리체의 감정과 반응 세기를 정해요. 오른쪽 스위치로 켜고 끄고, **키 입력 ›**으로 키 창을 열어요. 키가 없으면 스위치는 꺼짐으로 보이고, 누르면 키 창이 열려요. 켜면 대화의 일부가 미국의 TypeSafe AI로 가요. 직접 받은 JEV 키와 별도 크레딧이 필요하며 입력 토큰에만 요금이 붙어요. **자세히 ›**에서 [감정 판단 (JEV)](jev.md)을 읽을 수 있어요 |

대화창 프로그램이 꺼져 있으면 카드에 **리체 대화 꺼짐**이 보여요. 이때는 [문제 해결](troubleshooting.md)을 봐요.

## 모드

리체는 일상과 업무 두 대화를 따로 이어 가요. 모드는 대화창 위쪽 아이콘으로 바꾸고, 이 페이지에서는 바꾸지 않아요.

| 항목 | 설명 |
| --- | --- |
| 일상 | 잡담하는 대화예요. 누르면 일상 페이지가 열려요. 지금 보는 모드에는 **보는 중**이 붙어요 |
| 업무 | 일을 맡기는 대화예요. 누르면 업무 페이지가 열려요 |
| 지침 › 지침 폴더 | 공통 지침과 두 모드의 폴더가 든 지침 폴더를 열어요 (**폴더 열기**) |

연결한 에이전트가 모드별 대화를 지원하지 않으면 "이 연결은 아직 모드별 대화를 지원하지 않아요. 두 모드가 한 대화를 함께 써요."가 보여요. 이때는 두 모드 중 한쪽만 답을 기다릴 수 있어요.

### 일상, 업무 페이지

두 페이지의 구성은 같아요. 위쪽 **‹**를 누르면 모드 페이지로 돌아가요.

| 묶음 | 항목 | 설명 |
| --- | --- | --- |
| 옷차림 | 옷 | 이 모드에서 리체가 입을 옷이에요. **잠옷**과 **메이드복** 중에서 골라요. 기본은 일상 잠옷, 업무 메이드복이에요 |
| 옷차림 | 안경 | 이 모드에서 안경을 써요. 기본은 일상 꺼짐, 업무 켜짐이에요 |
| 지침 | 공통 지침 | 두 모드가 먼저 읽는 리체의 기본 지침 파일을 열어요 |
| 지침 | 일상 지침, 업무 지침 | 이 모드에서 리체가 읽는 지침 파일을 열어요 |
| 지침 | 일상 폴더, 업무 폴더 | 입구 파일(AGENTS.md)과 스킬 폴더(skills)가 든 폴더를 열어요 |
| 대화 | 모델 | 이 모드가 쓸 모델이에요. 누르면 연결한 에이전트가 알려 준 모델 목록이 펼쳐지고, 맨 위는 **에이전트 기본값**이에요. 모델 목록이 없는 에이전트(OpenClaw)는 **에이전트 기본값**만 보여요 |
| 대화 | 생각 깊이 | 고른 모델이 받는 생각 깊이를 칩으로 골라요. 맨 앞은 기본값이에요. 깊이를 고르지 않는 모델(예: Hermes)이면 "이 모델은 생각 깊이를 고르지 않아요", 에이전트가 모델도 생각 깊이도 알려 주지 않으면 "이 연결은 생각 깊이를 고를 수 없어요"가 보여요 |

옷과 안경을 바꾸면 그 모드를 보고 있을 때 리체가 바로 갈아입어요. 지침 파일은 [지침 파일](guides.md)에서 자세히 설명해요.

### 모드별 모델과 생각 깊이

- 일상과 업무는 모델과 생각 깊이를 **따로** 기억해요. 예를 들어 일상은 빠른 모델, 업무는 깊이 생각하는 모델로 둘 수 있어요.
- Claude Code, Codex, OpenClaw, Hermes 모두 그 에이전트가 알려 주는 모델과 생각 깊이를 보여 줘요. 고른 값은 바로 그 모드의 대화에 적용되고, 고른 모델이 받는 생각 깊이가 곧바로 다시 보여요. 리체를 다시 켜도 남아요. 에이전트별로 고를 수 있는 것은 [에이전트별 모델과 생각 깊이](agents.md#에이전트별-모델과-생각-깊이)에 있어요.
- 아무것도 고르지 않으면 연결한 에이전트의 기본값을 써요. 고른 모델을 에이전트가 더는 알려 주지 않으면 기본값으로 돌아가요.
- 대화창 머리글의 톱니바퀴를 누르면 보고 있는 모드의 이 설정으로 바로 와요.
- 에이전트가 모델도 생각 깊이도 알려 주지 않으면 "이 연결은 모델을 고를 수 없어요"가 보이고 고를 수 없어요. 대화창 프로그램이 꺼져 있으면 "리체 대화가 꺼져 있어 바꿀 수 없어요"가 보여요.

## 알림

다른 창을 보고 있을 때 리체의 소식을 데스크톱 알림으로 받아요.

| 묶음 | 항목 | 설명 |
| --- | --- | --- |
|  | 알림 받기 | 알림 전체를 켜고 꺼요. 꺼져 있으면 아래 항목은 쉬어요 |
| 받을 알림 | 답장 | 리체가 답을 보내면 알려 줘요 |
| 받을 알림 | 확인 요청 | 리체가 무언가 해도 될지 물으면 알려 줘요 |
| 알림 모양 | 내용 미리보기 | 알림에 답장 내용을 조금(최대 100자) 보여 줘요 |
| 알림 모양 | 소리 | 알림이 올 때 소리를 내요 |
| 더 보기 | 리체를 보고 있을 때도 알림 | 끄면 대화창이 앞에 있을 때 지금 보는 대화의 소식은 조용해요. 다른 모드의 소식은 계속 알려요 |
| 더 보기 | 테스트 알림 | 설정이 잘 됐는지 지금 한 번 보내 봐요 (**보내기**) |

운영체제의 알림이 꺼져 있으면 페이지 위쪽에 경고와 함께 **Windows 설정 열기** 또는 **시스템 설정 > 알림** 단추가 보여요.

## 화면

| 묶음 | 항목 | 설명 |
| --- | --- | --- |
| 테마 | 밝기 | **라이트**, **다크**, **시스템** 중에서 골라요. 시스템을 고르면 운영체제 설정을 따라요 |
| 테마 | 색 조합 | 말풍선, 입력창, 유리 빛을 한 번에 바꿔요. **리체 기본**, **벚꽃**, **밤하늘**, **모노**, **직접** 중에서 고르고, **직접 고르기 ›**를 눌러 같은 설정 카드 안에서 색을 하나하나 정해요 |
| 글자 | 글자 크기 | 대화창의 말풍선과 입력창 글자에 적용돼요. **작게**(14 px), **보통**(15 px), **크게**(17 px) 칩과 11 px부터 28 px까지 고르는 막대가 있어요. 칩에 없는 크기는 `직접 · 16 px`처럼 보여요 |

글자 크기는 카드 크기와 상관없이 따로 정해요. 카드를 키워도 글자는 커지지 않아요.

## 창

| 묶음 | 항목 | 설명 |
| --- | --- | --- |
| 창 | 항상 위 | 리체를 다른 창보다 위에 고정해요. 위젯의 고정핀과 같아요 |
| 창 | 카드를 화면 가운데로 | 리체가 화면 밖이나 메뉴 막대, 작업 표시줄 뒤로 가서 잡기 어려울 때 지금 크기 그대로 포인터가 있는 화면 가운데로 옮겨요 (**옮기기**) |
| 대화창 | 대화창 스타일 | **떠 있는 창**(유리 카드에 어울리는 떠 있는 대화창) 또는 테두리가 있는 **클래식 창** 중에서 골라요 |
| 대화창 | 캐릭터 옆에 두기 | 떠 있는 창에서 대화창 왼쪽, 캐릭터 오른쪽으로 나란히 붙여요. 클래식 창에서는 선택을 기억하고 쉬어요 |
| 대화창 | 대화창 배치 | **붙이기**는 대화창을 캐릭터 옆 유리판에 붙이고, **떼기**는 대화창만 따로 옮기고 크기를 바꿔요. 클래식 창은 늘 떨어져 있어요. 대화창 머리글의 단추와 같아요 |
| 작업 방해 줄이기 | 커서가 가까이 오면 흐리게 | 고정핀을 켰을 때 커서가 다가오면 카드가 흐려지고 클릭이 뒤 창으로 지나가요. 흐린 동안에도 Windows는 `Ctrl` 키, macOS는 `Option`(`⌥`) 키를 누른 채 다가가면 바로 대화할 수 있어요. **주의:** 흐린 카드 뒤가 바탕 화면이면 클릭이 바탕 화면에 닿아요. macOS에서 **시스템 설정 › 데스크탑 및 Dock › 배경화면을 클릭하여 데스크탑 보기**가 **항상**이면 창들이 옆으로 밀려나요. 카드를 누르려면 `Option` 키를 누른 채 다가가 카드가 진해지면 키를 놓고 눌러요 |
| 작업 방해 줄이기 | 흐려졌을 때 남는 진하기 | 흐려진 동안 리체가 얼마나 보일지 정해요 |
| 작업 방해 줄이기 | 전체 화면 앱이나 게임을 쓸 땐 숨기기 | 리체가 있는 모니터를 다른 앱이 전체 화면으로 쓰면 숨겼다가, 끝나면 다시 보여요. 기본은 켜짐이에요 |

카드를 화면 가운데로 옮기는 기능은 macOS에서는 Dock 아이콘 메뉴와 앱 메뉴(`⌥⌘L`)에도 있고, Windows에서는 창 메뉴(`Alt+Space`, 또는 작업 표시줄 단추를 Shift를 누른 채 오른쪽 클릭)에도 있어요.

## 성능

| 묶음 | 항목 | 설명 |
| --- | --- | --- |
|  | 성능 프로필 | **절약**, **균형**, **고품질** 중에서 골라요. 기본은 균형이에요. 아래 값을 하나라도 바꾸면 **사용자 지정**이 표시되고, 균형을 고르면 기본값으로 돌아가요 |
| 화질 (Windows) | 선명도 | **보통**과 **선명하게** 중에서 골라요. 선명하게는 외곽선이 매끄럽지만 GPU를 더 써요. 리체를 다시 시작해야 적용돼요 (**지금 다시 시작**) |
| 움직임 | 최대 프레임 | 1초에 리체를 그리는 최대 횟수예요. **15**, **30**, **60** 중에서 골라요 |
| 움직임 | 가만히 있을 때 프레임 | 리체 근처(카드 안이나 카드 높이의 절반 둘레)의 마우스 움직임, 누르기, 설정·대화 활동, 표정과 동작의 변화 없이 기본 대기 동작만 20초 넘게 이어지면 이만큼만 그려요. 15 아래로는 내리지 않아요. 멀리 다른 앱에서 마우스를 움직이는 것은 세지 않아요 |
| 아끼기 | 가려지면 쉬기 | 리체가 화면에 보이지 않는 동안(다른 창에 완전히 가려졌을 때 등) 그리기를 쉬어요. 대화와 알림은 계속 받아요 |
| 아끼기 (Windows) | 뒤 배경 흐림 | 끄면 리체 뒤를 흐림 없이 색만 칠해요. 조금 더 가벼워져요 |

| 프로필 | 가만히 있을 때 | 최대 프레임 | 그 밖의 값 (Windows) |
| --- | --- | --- | --- |
| 절약 | 15 | 30 | 선명도 보통, 뒤 배경 흐림 끔 |
| 균형 (기본) | 20 | 30 | 선명도 선명하게, 뒤 배경 흐림 켬 |
| 고품질 | 30 | 60 | 선명도 선명하게, 뒤 배경 흐림 켬 |

세 프로필 모두 **가려지면 쉬기**가 켜져 있어요. 0.2.0에서 균형과 고품질의 가만히 있을 때 프레임을 30·60에서 20·30으로 낮췄어요. 이전 버전의 균형·고품질 값을 그대로 가진 설정 파일은 새 값의 같은 프로필로 읽어요. 리체가 말하거나, 반응하거나, 끌리거나, 흐려지는 동안에는 늘 최대 프레임으로 그려요.

### Retina 화면 (macOS)

Retina 화면에서는 카드의 유리, 아이콘, 머리 위 표시, 글자와 **리체 설정** 창을 늘 화면의 픽셀대로 선명하게 그려요. 리체의 3D 모습은 성능 프로필에 맞춰 그려요. 프로필을 바꾸면 바로 적용돼요.

| 프로필 | Retina 화면에서 리체를 그리는 화질 |
| --- | --- |
| 절약 | 1배 (화면의 점 하나에 픽셀 하나) |
| 균형 (기본), 사용자 지정 | 1.5배 |
| 고품질 | 2배 (화면의 픽셀대로) |

Retina가 아닌 화면에서는 프로필과 상관없이 전과 같은 화질로 그려요. 화질을 높일수록 CPU와 GPU를 더 써요. 노트북에서는 **균형**이나 **절약**을 권해요. 카드를 다른 배율의 화면으로 옮기면 그 화면에 맞춰 바로 다시 그려요.

페이지 아래쪽 **지금 리체가 쓰는 양**에서 지금 프레임, CPU, GPU, 메모리 사용량을 1초마다 볼 수 있어요. 선명도를 빼면 바꾼 값은 바로 적용돼요. **지금 다시 시작**은 리체 캐릭터만 다시 띄우고, 대화와 연결은 끊지 않아요.

## 설정 창 밖에서 바꾸는 것

- **카드 위치와 크기:** 카드에서 직접 끌어서 바꿔요 ([처음 실행](first-run.md#기본-조작) 참고).

- 대화창을 여는 전역 단축키는 없어요.
