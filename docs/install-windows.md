# Windows 설치와 제거

[안내서 처음으로](../README.md)

## 필요한 것

- Windows 11 64비트 PC. Windows 10 동작은 확인 중이에요 (확인 중).
- DirectX 12 지원 그래픽 카드. 최소 CPU·GPU·메모리 사양은 저사양 PC 측정 전이에요 (확인 중).
- 내려받을 파일과 압축을 풀 저장 공간. 0.2.0 최종 용량은 확인 중이에요 (확인 중).
- 별도로 설치하고 로그인한 AI 에이전트. [에이전트 연결](agents.md)을 참고해요.

## 1. 내려받기

Gujo 스토어에 로그인한 뒤 라이브러리에서 Agent Liche의 Windows용 zip 파일을 내려받아요. Gujo Cloud Apps를 사용한다면 해당 상품의 설치 안내를 따라요.

1. zip 파일을 오른쪽 클릭하고 **모두 압축 풀기…**를 골라요.
2. 자주 옮기지 않을 폴더를 정하고 압축을 풀어요. 자동 시작은 실행 파일의 위치를 기억해요.
3. **패키지 맨 위의 `AgentLiche.exe`와 그 옆의 `AgentLiche` 폴더를 함께 두세요.** 실행 파일 하나만 옮기면 실행되지 않아요.

## 2. 처음 실행하기

1. 패키지 최상위 런처 **`AgentLiche.exe`**를 더블클릭해요. 내부 `AgentLiche\Binaries\Win64`의 파일을 찾아 실행할 필요는 없어요.
2. 바탕 화면에 유리 카드와 대화창이 나타나요.
3. [처음 실행](first-run.md)에 따라 에이전트를 연결해요. 리체의 대답은 연결한 AI 에이전트가 만들어요.

### "Windows의 PC 보호" 창이 뜰 때 (SmartScreen)

0.2.0 최종 파일의 코드 서명과 표시될 게시자는 아직 확인 중이에요 (확인 중). SmartScreen 경고가 나오면 파일이 Gujo 스토어에서 받은 정식 파일인지와 표시된 앱·게시자를 먼저 확인해요. 출처가 다르거나 악성 파일로 탐지됐다면 실행하지 말고 고객지원에 알려 주세요. 보안 기능을 통째로 끄지 마세요.

### 방화벽 창이 뜰 때

판매용 리체 캐릭터 프로그램은 외부 연결을 받는 포트를 열지 않아요. 수신 연결을 허용할 필요가 없어요. 리체의 방화벽 허용 창이 나오면 허용하지 말고 버전과 창의 내용을 고객지원에 알려 주세요. 별도로 설치한 에이전트의 연결은 그 프로그램의 안내를 따라요. [외부 연결 안내](privacy.md#바깥에-연결하는-경우)를 참고해요.

## 3. 끄기

- 리체 카드를 누른 뒤 `Alt+Space`의 창 메뉴에서 **닫기**를 골라요. 작업 표시줄 단추를 Shift를 누른 채 오른쪽 클릭해도 창 메뉴가 열려요 (확인 중: 최종 Windows 패키지).
- 꺼지지 않으면 작업 관리자(`Ctrl+Shift+Esc`)의 **세부 정보**에서 `AgentLiche.exe`를 골라 **작업 끝내기**를 눌러요. 앱 설명에는 Agent Liche가 여러 번 보일 수 있어요.
- 대화창 프로그램 `LicheInput.exe`는 리체가 꺼지면 함께 꺼져요.

## 4. 로그인할 때 자동으로 켜기

**리체 설정 › 일반 › 컴퓨터를 켜면 리체도 시작**을 켜요. 시작 프로그램 폴더에 `Agent Liche Auto Connect.lnk`가 생기고, 로그인할 때 리체와 저장된 연결이 함께 켜져요.

폴더를 옮기거나 버전을 바꿨다면 스위치를 껐다가 다시 켜요. 다른 시작 프로그램은 건드리지 않아요.

## 5. 제거하기

zip으로 설치한 리체는 폴더째 지워요. Gujo Cloud Apps로 설치했다면 먼저 그 클라이언트에서 제거해요. 클라이언트가 사용자 데이터까지 지우는지는 확인 중이에요 (확인 중).

1. 리체가 켜져 있을 때 **컴퓨터를 켜면 리체도 시작**을 꺼요. 이미 앱을 지웠다면 `Win+R`에서 `shell:startup`을 열고 `Agent Liche Auto Connect.lnk`를 지워요.
2. JEV 키를 지우려면 키 창의 **키 지우기**를 눌러요. 아래 데이터 폴더를 지워도 Windows의 키 파일이 지워져요.
3. 리체를 끄고 압축을 풀었던 프로그램 폴더를 통째로 지워요.
4. 필요한 파일을 먼저 복사한 뒤 아래 데이터 폴더를 지워요. **대화와 직접 만든 파일은 되돌릴 수 없어요.**

| 위치 | 들어 있는 것 |
| --- | --- |
| `%LOCALAPPDATA%\LicheWidget` | 대화 기록·첨부, 연결·화면·알림·성능 설정, 카드 위치, JEV 키(`chat\judge\typesafe.dpapi`), 진단 기록 |
| `문서\LicheWidget` | 위젯 설정 `settings.json`과 오류 파일 |
| `문서\Liche` | 공통·모드별 지침과 에이전트 작업 파일. 직접 만든 파일을 먼저 확인해요 |
| `%LOCALAPPDATA%\AgentLiche\Saved` | 엔진의 기록·임시 파일이 남아 있을 수 있어요 |

`Win+R`에서 `%LOCALAPPDATA%`를 열 수 있어요. **문서**는 탐색기 왼쪽의 문서 폴더이며 OneDrive 안에 있을 수도 있어요. 이전 버전의 `LizeWidget`, `Lize` 폴더는 [업데이트 안내](updates.md#이전-폴더-정리하기)에 따라 따로 정리해요.

연결한 에이전트는 별도 프로그램이어서 리체를 지워도 그 프로그램과 데이터는 남아요.
