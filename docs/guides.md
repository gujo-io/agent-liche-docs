# 지침 파일

[안내서 처음으로](../README.md) · [English](../en/docs/guides.md)

리체의 성격, 말투, 해도 되는 일과 하지 말아야 할 일은 지침 파일로 정해요. 지침 파일은 평범한 텍스트 파일(Markdown)이에요. 리체는 대화를 새로 시작할 때 첫 메시지에 이 파일들의 위치를 붙여 보내고, 에이전트가 그 파일을 읽어요. 파일은 여러분의 것이라 마음대로 고칠 수 있어요.

## 지침 폴더의 위치

| 플랫폼 | 위치 | 설정 창에 보이는 경로 |
| --- | --- | --- |
| macOS | 홈 폴더의 `Liche` (`~/Liche`) | `홈/Liche/…` |
| Windows | 문서 폴더의 `Liche` (`문서\Liche`) | `문서\Liche\…` |

## 폴더 구성

```text
Liche/
├── common.md            공통 지침: 두 모드가 먼저 읽어요 (기본 지침이 들어 있어요)
├── daily/               일상 모드의 폴더 (에이전트가 일상 대화에서 일하는 곳)
│   ├── AGENTS.md        일상 모드의 입구 파일 (기본 내용 없음, 원하면 직접 만들어요)
│   ├── daily.md         일상 지침 (기본 지침이 들어 있어요)
│   └── skills/          일상 모드에서 쓸 스킬
└── developer/           업무 모드의 폴더 (에이전트가 업무 대화에서 일하는 곳)
    ├── AGENTS.md        업무 모드의 입구 파일 (기본 내용 없음, 원하면 직접 만들어요)
    ├── developer.md     업무 지침 (기본 지침이 들어 있어요)
    └── skills/          업무 모드에서 쓸 스킬
```

- 각 모드의 에이전트는 그 모드의 폴더를 작업 폴더로 삼아 일해요. 업무 모드에서 에이전트에게 파일을 만들라고 하면 따로 경로를 말하지 않는 한 `developer` 폴더에 생길 수 있어요.

## 기본 지침

0.2.0부터 리체는 세 지침 파일 `common.md`, `daily/daily.md`, `developer/developer.md`의 **기본 지침**을 함께 배포해요. 새로 설치한 리체도 처음부터 리체답게 대답하도록 성격, 말투, 작은 말풍선에 맞춘 답 길이, 표정 태그 쓰는 법, 모드별 역할을 적어 두었어요.

- **없을 때만 만들어요.** 리체가 시작할 때, 모드의 대화가 시작될 때, 설정에서 그 파일의 **열기**를 누를 때 파일이 없으면 기본 지침으로 새로 만들어요.
- **여러분의 파일은 절대 덮어쓰지 않아요.** 이미 있는 파일은 고쳤든, 비웠든, 다른 내용으로 바꿨든 그대로 둬요. 업데이트해도 바뀌지 않아요.
- **지운 파일은 다시 생겨요.** 기본 지침 파일을 지우면 다음에 리체를 켤 때 기본 지침으로 다시 만들어져요.
- **지침을 끄려면 파일을 비워 두세요.** 내용이 빈 파일은 리체가 다시 채우지 않아요.
- **처음 상태로 되돌리려면 그 파일을 지우고 리체를 다시 켜요.**
- `AGENTS.md`에는 기본 지침이 없어요. 리체가 세 파일을 직접 알려 주므로, 에이전트가 같은 내용을 두 번 읽지 않게 하려는 거예요.
- 폴더에 쓸 수 없으면 리체는 파일을 만들지 않고 넘어가요.

### 모드에 맞지 않는 부탁

기본 지침에서 리체는 일상 모드에서 일을 부탁받거나 업무 모드에서 잡담을 들으면 **다른 모드를 한 번 권한 뒤, 여러분이 원하면 그대로 해요.** 모드 때문에 부탁을 거절하지는 않아요. 다르게 하고 싶다면 지침 파일을 고쳐요.

## 리체가 지침을 읽는 순서

대화를 새로 시작할 때 리체는 아래 순서로 파일의 위치를 에이전트에게 알려요. 그때 없는 파일은 건너뛰어요.

1. `common.md`
2. 그 모드의 `AGENTS.md`
3. 그 모드의 지침 파일(`daily.md` 또는 `developer.md`)

바꾼 지침은 그 모드의 다음 대화부터 적용돼요. 지금 이어지는 대화에 적용하려면 리체를 다시 켜요.

`AGENTS.md`는 많은 에이전트가 작업 폴더에서 먼저 찾아 읽는 입구 파일이에요. `skills` 폴더를 어떻게 쓰는지는 에이전트마다 달라요. 에이전트의 안내를 확인해요.

## 파일 여는 법

1. **리체 설정 › 모드**를 열어요.
2. **일상** 또는 **업무**를 눌러 그 모드의 페이지로 가요.
3. **지침** 묶음에서 **공통 지침**, **일상 지침**(또는 **업무 지침**)의 **열기**를 눌러요. 파일이 기본 텍스트 편집기로 열려요. 파일이 없으면 기본 지침으로 만든 뒤 열어요.
4. 폴더째 보려면 **일상 폴더**(또는 **업무 폴더**)의 **폴더 열기**를 누르거나, 모드 페이지의 **지침 폴더**에서 **폴더 열기**를 눌러요.

## 고쳐 쓰는 예시

기본 지침에 덧붙이거나 바꿔 쓸 때의 예시예요. 원하는 대로 바꿔 써요.

### `common.md`에 덧붙이기

```markdown
## 나에 대해

- 나를 "주인님"이라고 불러 줘.
- 대답은 짧게, 존댓말로 해 줘.
- 모르는 것은 모른다고 말해 줘.
```

### `daily/daily.md`에 덧붙이기

```markdown
- 여기서는 가볍게 잡담해 줘.
- 내가 코드 작업이나 파일 정리를 부탁하면 업무 모드를 한 번 권하고, 내가 그래도 해 달라고 하면 해 줘.
```

### `developer/developer.md`에 덧붙이기

```markdown
- 파일을 지우거나 덮어쓰기 전에는 꼭 먼저 물어봐 줘.
- 일이 끝나면 무엇을 했는지 세 줄로 정리해 줘.
```

## 알아 둘 것

- 지침을 얼마나 잘 따르는지는 연결한 에이전트와 모델에 따라 달라요.
- 지침 파일은 여러분의 컴퓨터에만 있어요. 리체를 지울 때 이 폴더는 직접 확인한 뒤 지워요 ([Windows](install-windows.md#6-제거하기), [macOS](install-mac.md#7-제거하기)).
- 지침 파일에는 비밀번호나 API 키를 쓰지 마세요. 에이전트가 이 파일을 읽고, 그 내용을 자기 AI 서비스로 보낼 수 있어요.
