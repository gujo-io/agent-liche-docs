# 지침 파일

[안내서 처음으로](../README.md)

리체의 성격, 말투, 해도 되는 일과 하지 말아야 할 일은 여러분이 쓰는 지침 파일로 정해요. 지침 파일은 평범한 텍스트 파일(Markdown)이에요. 리체는 대화를 새로 시작할 때 첫 메시지에 이 파일들의 위치를 붙여 보내고, 에이전트가 그 파일을 읽어요. 리체 앱은 지침의 내용을 쓰지 않아요. 처음에는 파일이 비어 있고, 무엇을 쓸지는 여러분이 정해요.

> 0.2.0에 기본 지침을 넣는 변경은 아직 통합 전이에요 (확인 중). 현재 안내는 빈 파일로 시작하는 동작을 기준으로 해요. 이미 직접 쓴 파일을 덮어쓰지 않는 방식으로 준비하고 있어요.

## 지침 폴더의 위치

| 플랫폼 | 위치 | 설정 창에 보이는 경로 |
| --- | --- | --- |
| macOS | 홈 폴더의 `Liche` (`~/Liche`) | `홈/Liche/…` |
| Windows | 문서 폴더의 `Liche` (`문서\Liche`) | `문서\Liche\…` |

## 폴더 구성

```text
Liche/
├── common.md            공통 지침: 두 모드가 먼저 읽어요
├── daily/               일상 모드의 폴더 (에이전트가 일상 대화에서 일하는 곳)
│   ├── AGENTS.md        일상 모드의 입구 파일
│   ├── daily.md         일상 지침
│   └── skills/          일상 모드에서 쓸 스킬
└── developer/           업무 모드의 폴더 (에이전트가 업무 대화에서 일하는 곳)
    ├── AGENTS.md        업무 모드의 입구 파일
    ├── developer.md     업무 지침
    └── skills/          업무 모드에서 쓸 스킬
```

- 폴더는 대화를 처음 시작할 때 비어 있는 채로 만들어져요.
- 파일은 **리체 설정**에서 그 줄의 **열기**를 누를 때 없으면 빈 파일로 만들어져요. 이미 있는 파일은 리체가 덮어쓰지 않아요.
- 각 모드의 에이전트는 그 모드의 폴더를 작업 폴더로 삼아 일해요. 업무 모드에서 에이전트에게 파일을 만들라고 하면 따로 경로를 말하지 않는 한 `developer` 폴더에 생길 수 있어요.

## 리체가 지침을 읽는 순서

대화를 새로 시작할 때 리체는 아래 순서로 파일의 위치를 에이전트에게 알려요. 없는 파일은 건너뛰어요.

1. `common.md`
2. 그 모드의 `AGENTS.md`
3. 그 모드의 지침 파일(`daily.md` 또는 `developer.md`)

바꾼 지침은 다음 대화부터 적용돼요. 연결한 에이전트에 따라서는 리체를 다시 켜야 새 지침을 읽을 수 있어요.

`AGENTS.md`는 많은 에이전트가 작업 폴더에서 먼저 찾아 읽는 입구 파일이에요. `skills` 폴더를 어떻게 쓰는지는 에이전트마다 달라요. 에이전트의 안내를 확인해요.

## 파일 여는 법

1. **리체 설정 › 모드**를 열어요.
2. **일상** 또는 **업무**를 눌러 그 모드의 페이지로 가요.
3. **지침** 묶음에서 **공통 지침**, **일상 지침**(또는 **업무 지침**)의 **열기**를 눌러요. 파일이 기본 텍스트 편집기로 열려요.
4. 폴더째 보려면 **일상 폴더**(또는 **업무 폴더**)의 **폴더 열기**를 누르거나, 모드 페이지의 **지침 폴더**에서 **폴더 열기**를 눌러요.

## 쓰는 예시

아래는 예시일 뿐이에요. 원하는 대로 바꿔 써요.

### `common.md`

```markdown
# 리체의 기본 지침

- 너는 내 바탕 화면에 사는 비서 리체야.
- 나를 "주인님"이라고 불러 줘.
- 대답은 짧게, 존댓말로 해 줘.
- 모르는 것은 모른다고 말해 줘.
```

### `daily/daily.md`

```markdown
# 일상 모드

- 여기서는 가볍게 잡담해 줘.
- 내가 코드 작업이나 파일 정리를 부탁하면 직접 하지 말고, 업무 모드로 바꿔서 부탁해 달라고 말해 줘.
```

### `developer/developer.md`

```markdown
# 업무 모드

- 여기서는 내 일을 도와줘.
- 파일을 지우거나 덮어쓰기 전에는 꼭 먼저 물어봐 줘.
- 일이 끝나면 무엇을 했는지 세 줄로 정리해 줘.
- 잡담을 시작하면 일상 모드로 가서 이야기하자고 말해 줘.
```

## 알아 둘 것

- 지침을 얼마나 잘 따르는지는 연결한 에이전트와 모델에 따라 달라요.
- 지침 파일은 여러분의 컴퓨터에만 있어요. 리체를 지울 때 이 폴더는 직접 확인한 뒤 지워요 ([Windows](install-windows.md#5-제거하기), [macOS](install-mac.md#7-제거하기)).
- 지침 파일에는 비밀번호나 API 키를 쓰지 마세요. 에이전트가 이 파일을 읽고, 그 내용을 자기 AI 서비스로 보낼 수 있어요.
