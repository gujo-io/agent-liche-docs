# 업데이트

[안내서 처음으로](../README.md)

리체에는 앱 안에서 스스로 업데이트하는 기능이 없어요. 새 버전이 나오면 스토어나 Gujo Cloud Apps에서 다시 내려받아 바꿔요.

## 업데이트를 받을 수 있는 기간

- 구매한 날부터 365일 동안 나오는 새 버전을 받을 수 있어요.
- 그 기간이 끝나도, 기간 안에 나온 버전은 계속 다시 내려받을 수 있어요.
- macOS 판이 나오면 같은 상품에 함께 들어가요. 업데이트 기간 안이면 추가 요금 없이 받을 수 있어요.

정확한 조건은 [스토어 상품 페이지](https://asset.gujo.io/products/287?lang=ko), [최종 사용자 사용권 계약 (EULA)](../legal/eula.md), [Gujo 이용약관](https://account.gujo.io/ko/terms)을 따라요.

## 지금 쓰는 버전 확인하기

- **리체 설정 › 리체 정보**에 `버전 2026.11.01 · abc1234`처럼 빌드 날짜와 빌드 번호가 보여요.
- 스토어에는 `0.1.0`처럼 버전 번호로 적혀 있어요.
- macOS에서는 앱 메뉴의 Agent Liche 정보 창에도 빌드 날짜가 보여요 (예정).

## Windows에서 업데이트하기

1. 스토어 라이브러리에서 새 zip 파일을 내려받거나, Gujo Cloud Apps에서 업데이트해요.
2. 리체를 꺼요 ([끄기](install-windows.md#3-끄기)). 이전 버전이 켜져 있으면 새 버전과 함께 뜰 수 있으니 꼭 먼저 꺼요.
3. zip 파일로 받았다면 새 폴더에 압축을 풀어요. 확인이 끝나면 이전 버전의 폴더는 지워도 돼요.
4. 새 폴더의 실행 파일을 실행해요. 처음 실행할 때 SmartScreen 창이 다시 뜰 수 있어요.
5. **컴퓨터를 켜면 리체도 시작**을 쓰고 있었다면 **리체 설정 › 일반**에서 이 스위치를 한 번 껐다가 다시 켜요. 바로 가기가 이전 폴더를 가리키고 있기 때문이에요.

대화 기록과 설정은 프로그램 폴더 밖(`%LOCALAPPDATA%\LicheWidget`, `문서\LicheWidget`, `문서\Liche`)에 있어서, 프로그램 폴더를 바꿔도 그대로 남아요. 단, 아래 "이름이 바뀐 업데이트"는 예외예요.

## macOS에서 업데이트하기 (예정)

1. 새 파일을 내려받아요.
2. Dock의 Agent Liche 아이콘을 오른쪽 클릭해 **종료**를 골라요.
3. 응용 프로그램 폴더의 `Agent Liche.app`을 새 앱으로 바꿔요. Finder가 물으면 **대치**를 눌러요.
4. 새 앱을 열어요.

macOS 판은 Developer ID로 서명해서, 한 번 허락한 알림과 키체인 사용은 업데이트 뒤에도 대개 그대로 이어져요 (예정). 처음 서명된 판으로 바꿀 때는 한 번 다시 물을 수 있어요.

## 이름이 바뀐 업데이트 (처음 설치처럼 시작해요)

다음 업데이트에서는 앱 안쪽의 이름을 Lize에서 Liche로 바꿨어요. 그래서 Windows 0.1.0을 쓰다가 이 업데이트를 처음 켜면 처음 설치한 것처럼 시작해요.

- 대화창의 연결 안내가 다시 나와요. 에이전트를 다시 연결해요.
- 설정은 기본값으로, 카드는 기본 자리로 돌아가요.
- 두 모드의 대화창이 빈 상태로 시작해요.
- 이전 버전의 기록과 설정은 지워지지 않고 이전 폴더에 그대로 남아요. 새 버전은 그 폴더를 읽지 않아요.

이전 폴더의 이름은 아래와 같아요. (확인 중: 0.1.0이 실제로 만드는 폴더)

| 이전 폴더 | 새 폴더 |
| --- | --- |
| `%LOCALAPPDATA%\LizeWidget` | `%LOCALAPPDATA%\LicheWidget` |
| `문서\LizeWidget` | `문서\LicheWidget` |
| `문서\Lize` (지침) | `문서\Liche` (지침) |

이전 지침 파일을 계속 쓰고 싶으면 `문서\Lize` 안의 파일을 `문서\Liche`로 직접 복사해요. 이전 폴더가 더는 필요 없으면 지워도 돼요. 에이전트에 리체의 MCP 서버를 이전 경로로 등록해 두었다면 새 경로로 다시 등록해요.
