# 업데이트

[안내서 처음으로](../README.md)

리체는 새 버전이 있는지 알려 주지만, 앱을 자동으로 내려받거나 설치하지는 않아요. 업데이트는 스토어나 Gujo Cloud Apps에서 직접 받아요.

## 새 버전 알림

- 기본으로 켜져 있으며, 하루에 한 번 GitHub의 작은 버전 안내 파일을 확인해요. **리체 정보**를 열 때도 확인할 수 있어요.
- 새 버전이 있으면 **리체 설정 › 리체 정보**에 **새 버전이 있어요**와 스토어 링크가 보여요.
- 원하지 않으면 **리체 설정 › 리체 정보**에서 새 버전 알림 스위치를 꺼요. 스위치의 정확한 이름은 **(확인 중)**이에요. 끄면 버전 안내 파일을 가져오지 않아요.
- 이 확인으로 GitHub(`raw.githubusercontent.com`)에 IP 주소가 전달돼요. 대화, 계정 정보, 기기 식별자는 보내지 않아요. [개인정보와 데이터](privacy.md)에서 자세히 설명해요.

## 업데이트를 받을 수 있는 기간

- 구매한 날부터 365일 동안 나오는 새 버전을 받을 수 있어요.
- 기간이 끝나도, 기간 안에 나온 버전은 계속 사용하고 다시 내려받을 수 있어요.
- Windows와 macOS(Apple Silicon) 판은 같은 상품에 들어 있어요.

정확한 조건은 [스토어 상품 페이지](https://asset.gujo.io/products/287?lang=ko), [최종 사용자 사용권 계약 (EULA)](../legal/eula.md), [Gujo 이용약관](https://account.gujo.io/ko/terms)을 따라요.

## 지금 쓰는 버전 확인하기

**리체 설정 › 리체 정보**에서 버전과 빌드 정보를 확인해요. 문의할 때 이 정보를 함께 알려 주세요.

## Windows에서 업데이트하기

1. 리체를 먼저 꺼요. 이전 버전과 새 버전이 함께 켜지지 않게 해 주세요.
2. 스토어 라이브러리에서 새 zip 파일을 내려받거나, Gujo Cloud Apps에서 업데이트해요.
3. zip 파일로 받았다면 이전 폴더에 덮어쓰지 말고 새 폴더에 압축을 풀어요.
4. 압축을 푼 패키지 맨 위의 `AgentLiche.exe`를 실행해요. 같은 곳의 `AgentLiche` 폴더도 그대로 두세요.
5. **컴퓨터를 켜면 리체도 시작**을 쓰고 있었다면 **리체 설정 › 일반**에서 한 번 껐다가 다시 켜요. 새 실행 파일의 위치로 시작 항목을 바꾸는 과정이에요.
6. 새 버전이 잘 열리는지 확인한 뒤 이전 프로그램 폴더를 지워요.

## macOS에서 업데이트하기

1. 새 macOS용 zip 파일을 내려받아 풀어요.
2. Dock의 Agent Liche 아이콘을 오른쪽 클릭해 **종료**를 골라요.
3. 응용 프로그램 폴더의 `Agent Liche.app`을 새 앱으로 바꿔요. Finder가 물으면 **대치**를 눌러요.
4. 새 앱을 열어요. macOS가 키체인이나 알림 사용을 다시 물으면 내용을 확인하고 답해요.

## 0.2.0은 처음 설치처럼 시작해요

0.2.0에서는 앱 이름과 내부 폴더 이름을 바꿨어요. 이전 버전에서 바꾸면 **설정, 대화 기록, 카드 위치, 에이전트 연결이 모두 빈 상태로 시작해요.**

- 처음 실행 안내에 따라 에이전트를 다시 연결해요.
- 설정과 카드 위치는 기본값으로 돌아가요.
- 일상·업무 대화 기록은 새로 시작해요.
- 이전 데이터는 지우거나 옮기지 않아요. 이전 폴더에 그대로 남고, 새 버전은 읽지 않아요.
- 이전 경로로 등록한 리체 MCP 서버나 작업 표시줄 고정 항목은 새 경로로 다시 등록해요.

### 이전 폴더 정리하기

먼저 이전 버전과 새 버전을 모두 꺼요. 필요한 대화 기록과 직접 만든 파일을 다른 곳에 복사한 다음 지워요. **지운 데이터는 되돌릴 수 없어요.**

| 플랫폼 | 이전 폴더 | 들어 있는 것 |
| --- | --- | --- |
| Windows | `%LOCALAPPDATA%\LizeWidget` | 이전 대화 기록, 연결, 설정, 카드 위치 |
| Windows | `문서\LizeWidget` | 이전 위젯 설정 |
| Windows | `문서\Lize` | 이전 지침과 에이전트 작업 파일 |
| macOS | `~/Library/Application Support/LizeWidget` | 이전 대화 기록, 연결, 설정 |
| macOS | `~/Library/Application Support/Epic/LizeWidget` | 이전 카드 위치와 크기 |
| macOS | `~/Documents/LizeWidget` | 이전 위젯 설정이 남아 있을 수 있어요 |
| macOS | `~/Documents/Lize` | 이전 지침과 에이전트 작업 파일 |

**Windows:** `Win+R`을 눌러 `%LOCALAPPDATA%`를 입력하고, 그 안의 `LizeWidget` 폴더를 지워요. 탐색기 왼쪽 **문서**에서도 `LizeWidget`과 `Lize`를 확인해 지워요. OneDrive가 문서를 백업한다면 그 안의 문서 폴더를 확인해요.

**macOS:** Finder에서 `⌘⇧G`를 누르고 위 경로를 하나씩 붙여 넣어요. 폴더가 있으면 필요한 파일을 확인한 뒤 휴지통으로 옮겨요. 경로가 없다는 안내가 나오면 그 항목은 건너뛰어요.

이전 프로그램 폴더와 엔진의 기록·임시 파일도 남을 수 있어요. Windows에서는 이전 패키지 폴더를 통째로 지우면 그 안의 `Saved`도 함께 지워져요. 사용자 폴더에 따로 남은 엔진 데이터는 `%LOCALAPPDATA%` 아래에서 **이전 실행 파일 이름에서 확장자를 뺀 이름**의 폴더를 찾아 지워요. macOS에서는 `~/Library/Application Support/Epic`과 `~/Library/Logs` 아래에서 **이전 앱 내부 실행 파일과 같은 이름**의 폴더를 확인해 지워요. `LicheWidget`과 `AgentLiche`는 새 버전이 쓰는 이름이므로 이전 폴더를 정리할 때 지우지 마세요.

이전 지침을 계속 쓰려면 Windows는 `문서\Lize`에서 `문서\Liche`로, macOS는 `~/Documents/Lize`에서 `~/Liche`로 필요한 파일을 직접 복사해요. 새 폴더에 이미 파일이 있으면 내용을 비교한 뒤 결정해요.
