# 감정 판단 (JEV)

[안내서 처음으로](../README.md) · [English](../en/docs/jev.md)

## 감정 판단이 하는 일

감정 판단(JEV)은 대화를 읽고 리체가 지을 표정, 반응의 세기, 기분을 골라 주는 선택 기능이에요. 켜면 리체가 메시지를 받을 때와 답의 말풍선마다 대화에 더 잘 맞는 표정을 지어요. 리체의 기분도 대화에 따라 조금씩 바뀌어요.

**꼭 켜지 않아도 돼요.** 감정 판단을 켜지 않으면 리체는 정해진 규칙대로 반응해요.

| 상황 | 감정 판단 없이 보이는 반응 |
| --- | --- |
| 답을 기다리는 동안 | 생각하는 얼굴 |
| 업무 모드에서 에이전트가 도구를 쓰는 동안 | 노트북을 두드리는 모습 |
| 승인 요청이 왔을 때 | 놀란 뒤 귀 기울이는 얼굴 |
| 첫 말풍선이 나올 때 | 살짝 웃는 얼굴 |
| 답이 끝났을 때 | 기뻐하는 얼굴 |
| 오류가 나거나 연결이 끊겼을 때 | 당황한 뒤 시무룩한 얼굴 |
| 거절당했거나 시간이 지났을 때 | 시무룩한 얼굴 |

감정 판단을 켜도 아직 판단이 오지 않았거나 판단에 실패하면 이 규칙 반응이 나와요. 감정 판단 때문에 대화가 멈추지는 않아요. 리체는 답을 다 받은 뒤 말풍선 판단을 최대 8초까지 기다렸다가 보여 줘요.

## 누가 운영하나요

JEV는 미국의 TypeSafe AI가 운영하는 서비스예요. 감정 판단을 켜면 리체의 판단 프로그램(`liche-judge`)이 TypeSafe AI의 서버(`api.typesafe.ai`)에 대화 내용을 보내고 판단 결과를 받아요.

## 키 받기

감정 판단을 쓰려면 여러분이 직접 받은 JEV 키가 필요해요. 리체에는 키가 들어 있지 않아요.

1. [TypeSafe AI 콘솔](https://console.typesafe.ai)에서 Google 계정이나 이메일로 가입해요. 누구나 가입할 수 있어요.
2. 먼저 크레딧을 구매해요. JEV는 크레딧을 미리 충전해서 쓰는 서비스예요(TypeSafe AI MCA 8.2).
3. [키 관리 페이지](https://console.typesafe.ai/keys)에서 키를 만들어요.
4. 만든 키를 아래 순서대로 리체에 넣어요. 키를 다른 사람에게 보내거나 공개하지 마세요.

요금은 **입력 토큰 100만 개당 미화 0.042달러**이고, **출력 토큰은 무료**예요. 리체 구매 금액에 JEV 크레딧은 포함되지 않아요. 결제와 이용 조건은 TypeSafe AI의 안내를 확인해요.

### 호출 횟수

0.2.0의 판단 프로그램(`liche-judge`)은 리체가 판단하는 대화 한 번(내 메시지 하나와 리체의 답 하나)마다 **JEV를 두 번** 불러요.

1. 메시지를 받았을 때 리체가 지을 감정을 고르는 호출 한 번
2. 답을 다 받은 뒤 말풍선마다의 반응을 고르는 호출 한 번

키를 저장할 때 키가 맞는지 확인하는 작은 호출이 한 번 더 있어요. 도구를 여러 번 쓰는 긴 업무 대화도 마지막 답만 판단해요. 실제 비용은 대화와 함께 보내는 문맥의 토큰 수에 따라 달라져요. 별도 프로그램인 리체 브릿지에 연결했다면 브릿지가 자기 방식으로 판단하며, 대화 한 번에 세 번 불러요.

## 키 넣기

키는 **감정 판단 (JEV) 키** 창에서 넣어요. 이 창은 세 곳에서 열 수 있어요.

- **리체 설정 › 연결 › 선택 기능 › 감정 판단 (JEV) · 선택**의 **키 입력 ›**
- macOS 첫 실행 안내의 **"감정 판단 (JEV) · 선택"** 단계의 **키 입력**
- Windows **연결 설정** 창의 **감정 판단 켜기 (선택)**

키 창에서는 이렇게 해요.

1. **JEV 키 붙여 넣기** 칸에 키를 붙여 넣어요.
2. **저장**을 눌러요.
3. 리체가 작은 JEV 호출 한 번으로 키가 맞는지 확인한 뒤 저장해요. 저장하면 감정 판단이 켜져요.
4. 창 위쪽에 **저장된 키: 있음**이 보이면 끝이에요. **닫기**를 눌러요.

Windows와 macOS 패키지에는 모두 판단 프로그램 `liche-judge`가 들어 있어요(Windows는 `AgentLiche\Binaries\Win64\liche-judge.exe`, macOS는 앱 안). "이 설치에는 감정 판단 프로그램이 없어요."가 보이면 이 파일이 빠진 거예요. 패키지를 다시 내려받아 풀고, 그래도 같으면 고객지원에 알려 주세요.

## 키는 어디에 보관하나요

키 창에서 **저장**을 누르면 대화창 프로그램이 키를 판단 프로그램에 `liche-judge --store-key` 명령으로 넘겨요. 이때 키는 **표준 입력(stdin)으로만** 전달되고, 명령줄 인자에는 들어가지 않아요. 그래서 같은 컴퓨터의 다른 프로그램이 실행 중인 명령줄을 봐도 키는 보이지 않아요. 판단 프로그램은 키를 확인한 뒤 아래 자리에 보관해요.

- **macOS:** 이 Mac의 로그인 키체인에 `com.agentliche.jev`라는 항목으로 보관해요. 판단 프로그램만 이 항목을 쓰고 읽어요.
- **Windows:** 이 Windows 사용자 계정으로 암호화(DPAPI)해 `%LOCALAPPDATA%\LicheWidget\chat\judge\typesafe.dpapi`에 보관해요. 다른 사용자 계정이나 다른 PC에서는 풀 수 없어요.

키는 화면에 다시 보이지 않고, 로그·진단 파일·설정 파일에 평문으로 남지 않아요. 판단 프로그램에 키를 명령줄 인자나 환경 변수로 넘기는 방법은 없어요.

## 바깥으로 보내는 정보

감정 판단이 켜져 있으면 대화 한 번마다 아래 정보가 TypeSafe AI(미국)로 가요.

- 내가 보낸 메시지
- 리체의 답과 그 답을 나눈 말풍선
- 바로 앞의 대화 최대 다섯 번(내 메시지와 리체의 답)
- 리체의 성격 설명, 지금 기분, 일하는 중인지에 대한 정보

감정 판단이 꺼져 있거나 키가 없으면 TypeSafe AI로는 아무것도 보내지 않아요. 이 정보는 TypeSafe AI의 약관과 개인정보 정책에 따라 처리돼요. 대화에 비밀번호나 개인정보 같은 민감한 내용이 있다면 감정 판단을 꺼 두기를 권해요.

## 끄기

**리체 설정 › 연결 › 선택 기능 › 감정 판단 (JEV) · 선택**의 스위치를 꺼요. 키는 그대로 남아 있어서 나중에 스위치만 다시 켜면 돼요. 끄면 그 순간부터 규칙 반응으로 돌아가요.

이 줄 아래에는 지금 상태가 보여요.

| 상태 | 뜻 |
| --- | --- |
| 켜져 있어요 | 감정 판단이 동작하고 있어요 |
| 꺼져 있어요 | 키는 있지만 꺼 두었어요 |
| 키를 넣으면 켤 수 있어요 | 키가 아직 없어요. 키를 지웠을 때도 이렇게 보여요. 스위치는 꺼짐으로 보이고, 누르면 키 창이 열려요 |
| 감정 판단이 멈췄어요 · 감정 판단을 하지 못했어요 | 키가 거절됐거나 서버에 닿지 않았어요. 스위치를 껐다 켜 보고, 계속되면 키를 다시 넣어요 |
| 이 설치에서는 감정 판단을 쓸 수 없어요 | 감정 판단 프로그램이 설치에 없어요. 리체를 다시 설치해요 |
| 이 연결에서는 쓸 수 없어요 | 지금 연결에서는 감정 판단을 쓸 수 없어요 |
| 준비 중 | 대화창 프로그램이 아직 감정 판단 정보를 보내지 않았어요 |

리체 브릿지에 연결했다면 브릿지가 직접 판단해서 "리체 브릿지가 판단해요"가 보이고, 여기서는 켜고 끌 수 없어요.

## 키 지우기

1. 키 창을 열어요 (**리체 설정 › 연결 › 감정 판단 (JEV) · 선택 › 키 입력 ›**).
2. **키 지우기**를 눌러요.
3. **저장된 키: 없음**이 보이면 지워진 거예요.

리체를 먼저 지웠다면 macOS는 [키체인 항목 지우기](install-mac.md#키체인-항목-지우기)를, Windows는 [제거하기](install-windows.md#6-제거하기)의 데이터 폴더 지우기를 따라 해요.

## macOS에서 키체인 창이 뜰 때

처음 키를 저장하거나 판단할 때 macOS가 `liche-judge`에 키체인 항목을 쓰게 할지 물을 수 있어요. 0.2.0부터는 Developer ID로 서명한 앱이라, 한 번 허용하면 다음 업데이트에서도 다시 묻지 않아요. **허용**이나 **항상 허용**을 눌러요. 답할 때까지 그 대화의 판단은 기다리고, 리체는 8초 뒤에 규칙 반응으로 답을 보여 줘요. **거부**를 누르면 키를 다시 저장할 때까지 감정 판단이 오류 상태로 남아요.
